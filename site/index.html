Your files stay put. Tags connect the dots.

An image can be a project reference, a facade study and something to discuss. Keep PDFs, images and web clips in the same search results without making extra copies.

01

Keep originals in place

Files normally stay at their original paths when added to your library. Keep editing them in your usual tools; Tagrove stores the tags and source information. If an original moves, relink it.

02

Many tags. One file.

Manage regular tags separately from automatic folder tags. Use aliases, colors, merging and synchronized renaming. Ctrl-click to select multiple files and tag them together.

03

See why it matched

Search names, tags, aliases, notes and indexed text. Each result shows where the match came from, so you can see why a reference was found.

From saved to useful.

Collect, tag, search, read and share. A connected workspace for the references scattered across your folders, drives and browser tabs.

See the reference, not just the filename.

Mix images, PDFs and web references in a visual workspace. Adjust columns, sidebar and inspector widths, with favorites, notes and sources close at hand.

  • Switch between masonry and list layouts; Ctrl + scroll adjusts columns.
  • Click a file to open the inspector; click it again to close.
  • Jump into Unsorted, Favorites, Recently added or Needs attention.

A small palette. A quicker way to tag.

Keep your tags in an always-on-top desktop palette. Expand categories, search, reorder with the grip or move tags between groups. Drag a tag onto a file, or drop a batch of files onto a tag.

  • Regular tags, folder tags and AI suggestions stay distinct.
  • Collapse to the title bar and control whether the palette stays on top.
  • Review the last three actions; Ctrl + Z undoes supported actions.

Search with whatever you remember.

Search names, tags, aliases, notes and indexed text together. Optional semantic results supplement those matches, and each result explains why it appeared.

  • Ctrl + F opens search, with matching excerpts and locations.
  • Combine type, status, included or excluded tags, folder and date filters into saved collections.
  • Unsupported, damaged, encrypted and oversized files show a status. Scans are not automatically processed with OCR.

Found it in your browser? Keep it.

The Chrome and Edge extensions save pages, selected text and images. Preview the capture, choose tags and save it. Read online or keep a captured copy, with the source URL preserved.

  • Save a page from the toolbar, or a link, excerpt or image from the context menu.
  • When the desktop app is offline, captures stay in a queue until imported.
  • Inspect failed stages, error codes and redacted diagnostics. Browser cookies are not read.

Useful locally. AI when you choose.

AI tagging and semantic search are separate, optional services. Review suggestions before they become regular tags. Semantic search needs an embeddings model. Check the endpoint, model, key and sending scope: analysis content goes to your configured service and may incur charges.

  • Captures with manually chosen tags are not automatically sent for AI tagging.
  • Generating embeddings for newly imported files still requires confirmation.
  • Operation history and recognition tasks have separate views.

A few things before you install.

The current release has some practical limits. Read these before setting it up on your computer or a colleague’s.

!Tested on Windows 11 x64. Windows 10 has not received equivalent device testing. No macOS or Linux installer is available.
!This release is not commercially code-signed, so Windows may show an unknown publisher warning. WebView2 is required; installation may need an internet connection.
!Real-time cloud sync is not available. Do not concurrently use an active SQLite / WAL library through a cloud-synced folder.
!The standalone EXE runs without an installer, but it still uses the current user’s library. It is not a portable library stored beside the EXE.
!Browser extensions currently require manual loading in developer mode. Their interface is in Chinese, and the desktop app must be running.
!Scans are not automatically processed with OCR. PPTX and text inside images are not covered by text indexing. Export an annotation backup before upgrading.
