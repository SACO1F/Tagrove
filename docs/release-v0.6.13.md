# v0.6.13 · Edge 网页采集（本地开发交付）

日期：2026-10-19。当前公开正式版仍为 v0.6.12；本轮未自动创建新 GitHub Release，也未提交 Edge Add-ons 商店。

## 功能

- 共用一套 Manifest V3 插件源码，生成独立命名的 Chrome / Edge 插件包，避免两套采集逻辑分叉。
- 桌面浏览器采集设置可选择 Microsoft Edge / Google Chrome，分别连接、修复和移除本机连接。
- 移除一个浏览器连接时保留另一个浏览器依赖的共享文件；不删除其他位置拥有的注册。暂停采集作用于所有浏览器。
- 两浏览器的草稿、离线队列、标签选择缓存各自保存在浏览器配置中，不自动互相同步。
- 支持原有网页、摘录、图片、手工标签、AI 规则、失败原因与原图补救流程。
- 开发者模式沿用固定扩展 ID，未放宽来源校验或增加浏览器权限。商店上架属于后续独立交付。

## 使用

1. 运行本轮 v0.6.13 桌面程序。
2. 解压 Edge ZIP，在 edge://extensions 开启开发人员模式并加载 manifest.json 所在文件夹。
3. 桌面偏好设置 → 浏览器采集 → Microsoft Edge → 连接 Edge 扩展。
4. Edge 工具栏或网页右键开始采集；检查标题、来源与标签后保存。
5. Chrome 用户选择对应浏览器连接；升级保留原扩展目录和队列。

## 实现依据

Microsoft 官方 Native Messaging 文档： https://learn.microsoft.com/en-us/microsoft-edge/extensions-chromium/developer-guide/native-messaging

Edge 使用 Microsoft/Edge/NativeMessagingHosts 注册位置；扩展来源仍为 chrome-extension:// 固定 ID。旧桌面 API 未提供 browser 字段时默认 Chrome，保持旧客户端兼容。
