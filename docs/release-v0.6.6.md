# v0.6.6 插件弹窗与预览体验

日期：2026-10-16。本轮本地交付，尚未发布 GitHub。

## 本轮变化

1. 右键采集不再新开页面，改为浏览器右上角的原生插件弹窗。Chrome 127+ 支持自动唤起；若被阻止则保留草稿，图标提示用户手动打开。扩展内容统一大圆角，外框仍由 Chrome 绘制。
2. 在线网页、原排版分别放在对应工具栏最左侧。
3. Excel 经 Microsoft／WPS 导出 PDF 原排版时，在隔离的只读工作簿中开启打印网格线，不写回源文件；更新缓存版本，旧 PDF 不再复用。LibreOffice 保留源文件打印设置，尚需对应环境验收。
4. 原排版、内容预览、在线网页、阅读副本、检测引擎沿用阅读／编辑的 34px 胶囊按钮、主题色与选择动效，增加一致的 14px 小图标；检测按钮也有同尺寸点击区域。
5. 引擎检测与选择仅在原排版模式展示；Office 默认先提供内容预览，切换后进行本机引擎检测。旧格式保留引擎路径。
6. 借鉴 Refine Frame 固定画框的加载思路，以页面占位、轻柔扫光和真实状态替代原排版转换中的转圈。无新增依赖、无虚构百分比，遵循减少动态效果设置。不是完整复制原组件。
7. PDF、图片、Office 原排版和流式内容的首次阅读默认适合页面；已有保存的用户缩放继续恢复。长文档按阅读宽度重排，不把全文压缩到一屏。在线网站保持自身响应式布局。

## 更新方式

升级前先导出标注备份并备份重要原件。退出旧程序，运行新 EXE 或安装包；替换原目录的扩展文件并重新加载，核对两端版本 0.6.6。移动 EXE 后修复 Chrome 本机连接。建议固定拾签扩展到工具栏，不要卸载或清除扩展队列。

数据库仍为 schema 7，资料包格式不变。在线网页和采集 AI 沿用 v0.6.5 修复；AI 关闭时不识别、未确认建议不进入普通标签池。
