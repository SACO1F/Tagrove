# 拾签 v0.6.9 · 网页采集失败诊断

本轮为 Chrome 扩展补充可排查的保存失败信息，桌面端同步版本号，数据格式不变。

- 弹窗和采集队列展示具体原因、失败环节、错误代码及处理建议。
- 保留底层错误与 HTTP 状态，区分连接、输入校验、图片下载／格式／大小、标签变化和存储失败；未知错误不再统一误报离线。
- 技术详情及复制诊断报告包含请求 ID、尝试次数、耗时、已知版本和来源站点；正文、完整链接与路径不进入报告，常见凭据脱敏，不自动上传。
- 保留失败队列及原重试规则，重试成功清理旧错误；旧记录明确提示原始信息缺失。

请同时更新配套扩展。解压扩展 ZIP 到固定目录；如果沿用原目录，覆盖文件后在 Chrome 扩展管理页点击重新加载。不要删除扩展后重装，以免清空本地队列。扩展 ID 保持不变；连接异常可在桌面偏好设置修复连接。
