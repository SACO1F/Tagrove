# 拾签 v0.5.7：增量语义索引与任务管理

本版让导入后的语义生成任务可以稍后找回，并复用未变化的正文样本，减少重复请求。内部版本、独立 EXE 与安装包均为 0.5.7；标注库 schema 3、资料包 format 3 不变。

## 找回导入批次

加入文件或文件夹后仍显示 5 秒生成提示。错过或选择暂不生成，可点击工作台底部“任务”打开后台任务，在“语义索引与待处理文件”中按批次筛选、勾选文件，再点击“预览所选范围”。新导入记录保存在本机，重启后可继续查看，但不会自动发送请求。

列表分别显示已缓存、待生成、等待正文索引、不支持正文、无可用正文、正文索引失败、模型已变化、正文已变化、生成失败、取消、中断与原文件不可用。每页 40 项，每次最多选择 500 个文件；最近最多保留 2,000 个非运行记录，超过后移出较旧记录。普通文件/文件夹导入会进入记录；浮窗直接标注、监听目录和资料包交接暂未增加专属批次记录，可通过语义设置手动建立缓存。

## 明确处理范围

预览窗口的“语义处理方式”提供三种选择：

- **补齐缺失并更新变化**：跳过有效缓存；内容样本未变时在本机更新来源和缓存版本；内容样本变化或模型不同才发送请求。
- **仅补齐缺失**：只处理当前模型没有缓存的文件。已存在但过期的缓存不会自动更新，也不会用于当前检索。
- **重新生成所选文件**：忽略已有缓存，重新发送所选文件的正文样本；确认前显示实际范围、模型、请求数与字符量。

向量复用比较同一模型、同一服务地址、按顺序发送的完整正文样本；不是只比较文件名、修改时间或正文长度。改变模型/服务地址不复用；样本位置变化而文字未变可重新关联来源。正文仍按已有首部、中部、尾部有限片段采样，不承诺覆盖全文。

一次确认最多发送偏好设置中的请求上限；本机复用不占模型请求数。预算不足的文件仍可稍后处理。需要原文件可用、当前正文索引完成；文件或计划变化时重新预览。

## 任务与失败恢复

后台任务显示本次完成文件数、已发送请求数、失败原因。遇到错误停止后续发送，已完成的缓存保留，失败及未完成文件单独记录。点击“预览失败与中断项”只打开范围预览；用户确认后才重试。取消丢弃迟到响应，已发送的请求可能计费；重启不恢复远程请求。

语义缓存和待处理记录属于派生数据，不随标注备份或资料包迁移。清理语义缓存同时清理待处理记录，原文件、标签和正文索引保留。

## 升级、限制与验证

建议退出旧版后启动本版独立 EXE，或覆盖安装。原文件和标注保留；旧版不能显示新增任务记录。500 个缓存文件、2048 维、32 MiB 逻辑内容预算保持不变，当前优先减少无效请求；实际 SQLite 文件还包含索引和日志开销。

图片视觉语义、OCR、真实模型质量和更大缓存容量不属于本版。测试采用合成文件与本机模拟向量服务；同事实机升级、跨电脑交接和长时间运行仍需实际验收。

## v0.5.7 experience.3：单层标签分类

最新修订目录 `releases/v0.5.7-experience.3`，内部版本仍为 0.5.7，标注 schema 3 和资料包 format 3 不变。

在工作台“管理标签”中展开“管理分类与标签归属”，可创建、改名、前移/后移、删除分类，并为普通标签选择分类。浮窗右上角文件夹图标同样打开分类管理；标签九宫格的“移动到分类”可调整单个标签。

首版为一层分类，每个普通标签归属一个分类；未分配的标签进入“未分类”。分类是容器，不自动成为文件标签。删除分类会将标签归还未分类，不删除标签、颜色或文件关联。文件夹标签保持独立；未确认 AI 建议不能归类，确认后可进入未分类再整理。分类名称最多 40 字、最多 100 个，未分类为保留名称。

工作台侧栏按分支树展开；浮窗分类展开后保留两列彩色标签，空分类不占浮窗空间。分类标题只展开/收起，点击子标签继续筛选或标注。展开带连接线、箭头旋转和缓进缓出过渡，尊重系统减少动画偏好。工作台和浮窗分别记忆收拢状态；浮窗搜索临时展开匹配分类，清空搜索恢复记忆状态。

九宫格拖动和前移/后移仅调整同一分类内的浮窗标签顺序；拖到另一分类松开会取消，跨分类使用“移动到分类”。标签主体拖到文件标注仍保留。

分类更新带版本检查，其他窗口先修改时拒绝覆盖并提示刷新。分类与展开状态为本机资料库配置，随完整标注备份保存；本轮资料包交接不迁移分类。旧版本不显示分类。
