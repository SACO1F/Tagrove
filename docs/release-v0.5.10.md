# 拾签 v0.5.10：搜索质量与命中解释

本地 Windows x64 版本，保留 v0.5.9 阅读状态和现有资料库。此轮未上传 GitHub。

- 统一搜索的相关度排序区分准确文件名、文件名前缀、准确标签、准确别名、文件名包含匹配、跨字段和正文；明确的本地结果优先于语义补充。
- 搜索结果显示简短命中来源，悬浮查看具体文件名、标签或别名；未搜索与清空后隐藏。标签本身保留各自颜色。
- 正文片段在各关键词首次出现位置之间，优先选择覆盖更多不同关键词的片段，保留原有页码及正文定位。
- 每次查询绑定对应片段和命中原因，切换、清空关键词时不会继续显示上一查询的证据。

范围：不新增 OCR、图片视觉理解或自动同义词扩展。仅含关键词的搜索仍要求现有字段或正文实际匹配；语义功能依赖支持 embeddings 的服务。图片的“风景／室内”等查询通过文件名、标签和备注匹配。

使用前退出旧版，建议导出一次标注备份。直接运行 EXE 与安装版使用同一正式资料库，勿同时运行。
