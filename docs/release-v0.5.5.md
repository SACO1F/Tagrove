# 拾签 v0.5.5：可选语义检索与自然语言筛选

2026-10-14。Windows x64 本地交付，本轮未上传 GitHub。

## 本版功能

- 搜索栏新增「智能查找」入口，提供「语义查找」与「自然语言筛选」两种方式，沿用绿色主题、分段切换与现有下拉控件。
- 语义检索默认关闭。偏好设置中自行配置兼容 `/embeddings` 的服务地址、向量模型和独立密钥；勾选发送授权后保存。HTTP 仅限回环地址，远程地址须 HTTPS；不跟随重定向。应用不捆绑模型、不下载模型、不启动第三方服务。
- 建索引前展示服务、模型、文件名、本轮请求数、每文件样本数和字符数；确认后才发送。仅从当前有效正文索引中选取最新 500 个已导入文件，每文件首／中／末最多三段、每段最多 1000 字符，按段落来源截短。单轮 1～200 个文件请求，默认 100，串行处理。
- 手动取消后保留已完成缓存，丢弃迟到结果；重启只显示中断，不自动继续发送。网络错误中止本轮；重新预览可继续未完成文件。单请求超时 30 秒；取消不能撤回服务已收到的请求。
- 搜索时明确点击发送一条查询，展示实际来源片段和余弦相似度。排序按相关度，文件类型、标签、状态等筛选继续有效；翻页与修改筛选复用临时结果，不重新请求模型。最多八个会话，十分钟过期。
- 自然语言筛选在本机使用规则解析，先列出条件，再确认替换当前筛选，不调用模型、不修改原文件。支持最近7天、最近30天、最近一周、最近一个月、今天（滚动24小时），按修改时间；图片、PDF、Office、文本；收藏、待整理、需要关注；带引号的包含／排除标签和普通标签别名。多个类型匹配任一类型，包含标签要求全部满足。未列出的描述不会被解释，复杂否定和自由语义条件仍需使用工作台筛选。

## 使用流程

1. 偏好设置 → 正文索引 → 启用并等待处理完成。
2. 偏好设置 → 语义检索 → 填写兼容服务地址、实际可用的向量模型名称和密钥。本机服务可以没有密钥，远程服务可能收费。启用、确认发送授权，保存。
3. 点击「预览发送范围」，核对文件和字符预算，再点击「确认发送并建立」。更改设置后必须先保存并重新预览。
4. 工作台 → 展开搜索栏 → 输入想找的内容 → 智能补充 → 发送查询并补充。结果片段显示语义来源，不能把相似度视为确定命中或置信度。
5. 不配置模型也可选择「自然语言筛选」，例如 `最近7天的 PDF，包含「参考素材」，排除「已完成」`。核对条件后应用，可以继续通过筛选栏编辑或保存为普通筛选集合。

## 边界与隐私

语义服务只收到模型名称、正文样本或查询文字；不自动附加文件路径、文件名、标签和整份原文件，但正文自身可能含敏感信息。密钥使用 Windows DPAPI 单独保存，不与自动标注密钥混用，更换服务地址且不填写新密钥时会清除旧密钥。

向量最多 2048 维；样本与向量逻辑内容预算为 32 MiB，SQLite 索引和 WAL 会产生额外磁盘开销，设置中分别展示。仅有抽样覆盖，扫描 PDF、未提取格式、未完成正文索引的文件没有语义结果，不包含图片视觉语义或 OCR。实际效果取决于模型的中文能力及样本覆盖；若模型返回维数改变，请清理缓存重建。

向量和样本属于派生缓存，不随资料包／标注备份交接。备份不携带语义配置、密钥或发送授权；恢复后必须重新配置和手动建立。清理语义缓存不会删除原文件、标签、备注或正文索引。损坏缓存会隔离到 `cache/semantic/*.corrupt-*` 并重建空缓存，隔离副本可能含旧正文样本，普通清理不删除隔离副本。精确元数据／正文检索保持独立可用。

保持元数据库 schema 3、资料包 format 3，与 v0.5.4 的标签别名兼容；旧版程序不能使用新语义功能。临时语义结果不能保存为集合。源文件改变后刷新状态并等待正文索引完成，再预览建立新向量。

接口字段依据 [OpenAI Embeddings 文档](https://developers.openai.com/api/reference/resources/embeddings/methods/create)；本机服务兼容能力应核对 [Ollama 兼容接口文档](https://docs.ollama.com/api/openai-compatibility)，模型须由用户安装和选择。不会自动配置或发送真实付费请求。

## 2026-10-14 体验修订 1

直接运行程序位于 `releases/v0.5.5-experience.1/Shiqian-v0.5.5-Windows-x64.exe`，内部版本保持 0.5.5，与此前原版二进制不同。

- 偏好设置中的语义检索与 AI 自动标注启用控件采用 React Bits SquishSwitch：轻微滑块拉伸、平滑归位、主题绿色、点击与拖动、键盘空格/回车、禁用状态、减少动效支持。
- 语义服务域名/端口根地址自动补齐 `/v1/embeddings`；已填写 `/v1`、自定义服务前缀或完整 `/embeddings` 的地址保留。设置显示实际请求地址，无自动网络探测或多地址重试。
- DeepSeek 官方当前公开接口没有 Embeddings；其 deepseek-flash 是对话模型。配置官方地址启用语义检索时，在发送之前提示更换向量服务和向量模型。AI 自动标注配置不受该检查影响。
- 404 提示明确接口或模型未找到；401/403 提示密钥或权限问题。重新配置向量服务后，需要保存、预览发送范围、确认建立索引。
- 根地址请求目标发生变化时，旧向量缓存不再视为当前配置可用；已经正确配置 `/v1` 的缓存标识保持一致。

接口依据：[DeepSeek 模型](https://api-docs.deepseek.com/api/list-models/)、[Ollama OpenAI 兼容接口](https://docs.ollama.com/api/openai-compatibility)。支持 OpenAI 格式的向量接口，不支持把 Ollama 原生 `/api/embed` 当作兼容接口。
