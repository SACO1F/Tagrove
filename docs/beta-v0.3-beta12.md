# 拾签 v0.3.0-beta.12 本地候选

2026-10-10。本轮修复和研究已在主项目 D:\AI\Shiqian 完成，以 Beta.12 预发布候选交付，仍需稳定版实机验收。

## 修复

侧栏分隔条原本会被后加载的全局 tabindex 焦点规则套用 2px 绿色外框，尤其是键盘使用后或输入框焦点切换后。专用 focus-visible 规则现在覆盖全局外框，交互通过细竖线反馈；方向键、Home/End、Enter 和拖动仍可使用。主动聚焦增加 preventScroll，避免焦点引起页面滚动。

## 首次启动说明

上轮在隔离可写副本开发的两步引导已合入主项目。首次进入工作台显示 AI 配置提醒，保存成功或暂不设置后显示四步使用说明。无效设置保留表单；保存期间禁止跳过/关闭；已有配置不清除。完成后不再自动弹出，偏好设置可重新查看。

首次记录保存在本机 WebView 存储，以资料库路径区分。旧版升级无记录时也会提示一次；清除 WebView 存储可能重新触发。引导本身不调用 AI，启用自动标注仍由用户勾选。

## 预览研究

本轮未启用新的 Word/Excel 预览功能，也未向生产依赖添加对应库。研究位于源码包的 `docs/file-preview-research-2026-10-10.md`，包含当前 PDF.js 实现、实测库资源大小、方案边界和开发顺序。

## 安装

关闭正在运行的拾签，运行同目录 `Shiqian-v0.3.0-beta.12-Windows-x64-setup.exe`。建议先备份现有标注；标注备份不含原文件，交接文件请使用资料包。
