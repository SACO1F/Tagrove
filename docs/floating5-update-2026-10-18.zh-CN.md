# v0.6.11-floating.5 更新说明

日期：2026-10-18

## 标签拖放立体动效

从浮窗把标签拖到工作台的图片或文件上时，目标卡片会根据鼠标位置轻微倾斜，并略微抬起，离开或松开后平滑复位。列表行采用更小的倾斜幅度。标签名称和松手提示继续显示，拖放命中使用未倾斜的卡片区域。

在“偏好设置 → 外观 → 标签拖放立体动效”中开启或关闭，默认开启并保存选择。关闭后保留普通目标提示和标注功能。系统开启“减少动态效果”时不启用倾斜。

视觉方向参考 [React Bits Tilted Card](https://reactbits.dev/c/components/tilted-card)，通过项目已有拖放事件和 CSS 变换实现，没有新增运行依赖。

## 可展开的偏好设置

偏好设置分为使用说明、外观、文件夹自动标签、AI 自动标注、正文索引、语义检索、资料交接、文件位置、浏览器采集、备份与恢复、本地存储 11 个模块。默认显示分组标题，点击标题或右侧箭头查看具体设置，可同时展开多个模块。

展开与收起使用平滑过渡；支持 Tab 聚焦标题、Enter 或空格展开。收起后内部控件不可获取键盘焦点，已经输入但未保存的表单内容仍保留。首次启动的 AI 设置向导与后台任务中的索引面板保持直接展示。

应用内部版本仍为 0.6.11；请按 releases/v0.6.11-floating.5 目录与程序文件名区分此前版本。
