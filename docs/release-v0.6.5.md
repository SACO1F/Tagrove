# v0.6.5 网页预览修复与采集标签

日期：2026-10-16。本轮为本地交付，尚未发布 GitHub。

## 本轮变化

- 修复在线网页始终隐藏的问题：旧逻辑误将工作台文件列表识别为弹出菜单；现在只处理实际遮挡网页的弹层。详情和放大预览使用独立会话，避免相互关闭；网页资料现在正确进入放大内容阅读器。
- 浏览器新采集的链接、摘录和图片，在桌面 AI 自动标注启用时自动排队。链接优先使用采集的正文摘要，否则使用标题与来源；摘录使用正文；图片沿用图像识别。结果仍为待确认建议，未确认的新标签不进入可复用标签池。
- 扩展保存前可搜索、多选已有普通标签；文件夹标签和未确认 AI 标签不出现。手动标签与资料一起写入，AI 不覆盖。每次最多选 50 个，目录返回最多 500 个匹配结果，可继续搜索。
- 标签目录有本地缓存，桌面离线仍可整理选择并暂存队列。标签被删除时明确提示，在队列点“重新编辑”后用新请求提交；同 ID 重试与内容去重不重复排 AI。
- 网页链接采集尽力读取页面可见正文，保存最多 12,000 字符的阅读摘要。不读取登录凭据或表单输入值，不代表整页离线存档；浏览器权限或页面结构限制时回退为链接元数据。

## 更新与使用

1. 升级前导出标注备份，重要原文件另行备份。退出旧程序，再运行本轮 EXE 或安装包。
2. 在扩展原目录替换新版文件并重新加载，核对桌面和扩展均为 0.6.5；保留 Chrome 配置和扩展数据。移动 EXE 后在偏好设置修复 Chrome 连接。
3. 网页资料 → 内容 → 在线网页；点击放大预览后也可选择在线网页。只对带来源的网页资料提供此入口，普通本地 HTML 沿用静态预览／源码。
4. 若希望采集后自动标注，在桌面偏好设置启用并配置 AI。扩展保存时选择已有标签，随后在桌面 AI 建议审核中确认建议；关闭 AI 时不会发识别请求。

数据库仍为 schema 7，无新增迁移。网页图片资料包仍为格式 7；含阅读副本的包为格式 6。新扩展的标签与正文选项需要桌面 0.6.5。在线网站不共享 Chrome 登录，站点、网络、证书限制仍可能导致访问失败。旧采集不会升级后自动全部补识别，可在桌面手动识别。
