# 拾签 v0.4.0：PDF 分页阅读

日期：2026-10-11。本轮本地开发交付，GitHub 最新公开版本仍为 RC.4。

## 新增能力

- 放大 PDF 预览时打开分页阅读器，显示总页数与当前页。
- 上一页、下一页、页码跳转及方向键/PageUp/PageDown 翻页；输入超出范围时自动限制在有效页码。
- 25%～300% 缩放、适应宽度，窗口变化后重新适配。
- 加密 PDF 支持本次会话密码输入及错误重试，密码不写入资料库。
- 按需渲染当前页；切页取消旧渲染，关闭/切换销毁文档任务，旧 IPC 响应不会重新挂载已关闭预览。
- 取消加载与重新加载；损坏、不可访问或超过 30 MiB 的文件显示错误，并保留打开原文件入口。

卡片和详情仍使用首页缩略图。阅读器绕过缩略图缓存读取原 PDF，校验原文件版本与身份。原有 PDF.js 依赖和资源复用，无新增阅读依赖；仅保留当前页画布，像素预算约 8 MP，像素边长最大约 8192。阅读器只读，不执行 PDF 脚本，不提供编辑、表单填写或文字选择层。

## 使用

选中 PDF，在详情点击“放大预览”，或在工作台按 Space。用工具栏翻页、输入页码后按 Enter；聚焦页面后也可用方向键翻页。关闭预览释放本次阅读资源，再次打开从第一页开始。

PDF 字体、扫描内容和复杂版面可能因文件本身与 WebView 环境存在差异；无法阅读时使用默认程序。DOCX/XLSX 内容阅读器仍留待后续版本。
