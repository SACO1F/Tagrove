# 拾签 v0.5.6：搜索质量与体验

本版改进统一搜索的跨字段匹配、相关度排序、范围控制与服务连接测试。内部版本、独立 EXE 和安装包均为 0.5.6；数据库 schema 3、资料包 format 3 不变。

## 新的搜索行为

输入“学习 卷子”，可以找到名称含“学习”、正文含“卷子”的同一文件。每个空格分隔词都要在该文件的允许字段中出现；词序不影响结果。all 范围包括名称、标签/别名、备注及当前有效正文；缺少或失效的正文不作为匹配依据。仅信息命中不显示不相关片段，跨字段正文片段以实际出现在正文的词为起点。

相关度依次考虑：文件名或去掉扩展名的名称完整匹配、所有词在文件名、所有词在文件信息、信息与正文混合、仅正文、仅语义补充。语义排名仍只用于同层结果，不直接相加不同量纲分数。名称/时间/大小排序继续按对应字段。

## 搜索范围与无结果提示

筛选面板新增“搜索范围”，可选全部、仅文件名、仅正文。主搜索栏保持一个输入框；范围切换清除旧智能会话。仅文件名不使用智能补充，按钮禁用；仅正文需要开启索引。空查询显示符合其他筛选条件的全部文件。当前范围可随普通筛选集合保存，旧集合默认全部范围。

无结果时提示当前范围与图片/正文索引限制。中文短词、标签别名、大小写和标点继续按规范化子串匹配；不支持正则或自由布尔表达式。关键词仍限 256 字符/16 词。

窄窗口和详情栏展开时收紧输入框周围间距，搜索保持单行；完整文件名可通过已有悬浮提示查看。

## 向量服务连接测试

偏好设置→语义检索→先保存服务配置→“测试连接”。一次点击仅发送一段固定合成文字，不读原文件、不建立或清除缓存。显示实际请求地址、模型、向量维度与耗时。测试可能产生服务费用；没有自动探测、自动重试或多个地址试探。未保存配置/正在建立任务时按钮不可用。2048 维与 1 MiB 响应等现有限制继续生效。

## 升级与边界

继续提供导入后本批生成提示和单实例/关闭修复。新范围字段不改变数据库结构；建议同事统一使用本版，旧软件可能忽略新集合的范围字段。普通标签、备注、原文件与现有缓存保留。

图片按名称、标签、别名和备注检索；本版没有图片视觉语义或 OCR。真实模型的检索质量不是连接成功即可证明。
