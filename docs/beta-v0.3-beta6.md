# 拾签 v0.3.0-beta.6 体验修复指南

日期：2026-10-10。候选版本用于小范围试用；安装环境、多屏和全天使用验收完成后再评估稳定发布。

## 安装与升级

本地交付：`releases/v0.3.0-beta.6/`。

- 推荐安装 `Shiqian-v0.3.0-beta.6-Windows-x64-setup.exe`。
- 已有 WebView2 的电脑可运行 `Shiqian-v0.3.0-beta.6-Windows-x64.exe`；独立 EXE 使用 Windows 用户应用数据目录。
- 升级前导出 `.sqtagbackup`，重要原文件另行备份；等待或取消后台任务，退出工作台与浮窗，再安装候选。
- 升级后核对版本、文件、标签、备注、收藏和设置。数据库保持 schema 2。
- 卸载器提供删除应用数据选项；希望保留标注时不要选择该项，并先导出备份。生成安装脚本已检查，实际卸载重装的数据保留行为仍需测试电脑验证。
- 安装器覆盖升级与缺少 WebView2 环境仍需测试电脑验证。

## 本轮修复

- 拖动标签的鼠标提示按真实宽高避让窗口边缘；靠近右边缘时移到鼠标左侧，取消固定 260 像素限制。实际文件命中检测与高亮继续按鼠标坐标进行。
- 状态筛选、标签匹配、文件排序、卡片密度共用 Glide Select 风格的弹出菜单：弹出 180ms、收回 120ms、滑动高亮 220ms；采用拾签主题色，支持方向键、Home/End、Enter/Space、Escape、点击外部关闭、减少动态效果。菜单独立挂在页面顶层，避免被筛选面板裁切，并在空间不足时向上展开。
- 工作台新建普通标签（包括未选中文件时）及给文件添加已有普通标签，会自动同步到标签浮窗；保留已有快捷标签、不重复添加。文件夹标签不加入浮窗；AI 建议仍须用户明确确认或使用后才能进入浮窗。
- 工作台与浮窗添加标签按钮移除白色边缘和内侧亮线，保留半透明玻璃底色、模糊与柔和外阴影；键盘焦点轮廓保留。
- 保留 Beta.5 的同标签文件批量添加和侧栏对齐，以及 Beta.4 的滚动稳定。

参考页面：[React Bits Glide Select](https://reactbits.dev/c/micro/glide-select)。本项目依照展示交互独立实现，使用既有图标与 CSS，不增加第三方图标依赖。

## 浮窗位置

移动或调整浮窗后保存位置及展开尺寸；折叠不覆盖展开尺寸。重启打开浮窗时恢复位置，并根据当前显示器工作区校正。显示器已拔除或旧位置不在有效范围时回到主屏工作区。

尺寸按逻辑像素保存，位置按物理屏幕坐标保存。混合 DPI 与跨屏原生拖拽仍需实机核对。浮窗位置不写入跨设备标注备份，避免把一台电脑的坐标带到另一台。

## 后台任务与退出

资料包校验、复制、导出可点击「后台运行」，从底栏任务入口查看或取消。准备期间可以浏览、搜索和保存既有文件备注；最后提交事务可能短暂等待。

原生关闭／退出也检查活动任务。普通文件加入取消后，已完成记录保留；等待任务停止再退出。任务仍在收尾时查看任务面板，不强制终止进程。

若浮窗仍显示，关闭工作台会隐藏主窗口；从浮窗可以重新打开工作台。完全退出前先关闭浮窗，再关闭工作台。

## 交接与反馈

发给同事：候选安装包＋从软件导出的 `.sqtagpack`。同事在「偏好设置 → 资料交接」校验后选择接收目录并导入。`.sqtagbackup` 用于标注备份，不包含原文件。

诊断报告在偏好设置预览后导出，仅包含版本、计数与任务状态，不包含文件名、路径、正文、备注、标签名或 AI 服务配置，不自动上传。

实机检查表沿用源码快照的 `docs/beta3-real-device-checklist.md`，支持人员按场景记录结果、复现步骤、影响范围和诊断报告。

发布前核对源码六处版本、安装包和 EXE 原生产品版本；已有交付程序与当前构建不同则停止。只有确认构建验证完成后才使用 `scripts/package-release.py --refresh-binaries` 显式刷新同版本候选文件。

使用与验收结果见 候选验收记录（历史资料，见 v0.6.12 源码快照）。开发格式与 API 约定见 资料包格式 v1（历史资料，见 v0.6.12 源码快照）。
