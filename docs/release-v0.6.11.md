# 拾签 v0.6.11 · 界面文字与偏好设置

- 修复英文模式左侧导航收起时的中文悬浮提示。

运行本目录 Shiqian-v0.6.11-Windows-x64.exe，或使用 setup 安装包。已有资料库会沿用，旧版未设置字号时采用默认字号。浏览器扩展功能沿用 v0.6.10，本轮不要求更换现用扩展。
