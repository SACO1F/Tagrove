# 拾签 v0.5.0：本地正文搜索

2026-10-12。本地开发交付，公开 GitHub 下载仍为 RC.4；本轮未上传。

## 新增功能

- 点击工作台标题旁的搜索图标，切换「文件信息／文件内容」。文件信息继续搜索名称、标签、备注；文件内容搜索已加入的 TXT、MD、Markdown 正文，并与标签、类型、目录、日期、排序共同生效。
- 正文结果在瀑布流和列表中显示短片段、正文来源、编码及部分内容标记。双击可打开原文件；首版不提供正文行号跳转。
- 偏好设置和后台任务新增「正文索引」。默认关闭，主动启用后仅处理资料库中的支持格式，不扫描全盘，不调用 AI，不上传正文。
- 支持暂停、继续、取消、重建和清除。暂停／取消保留已完成索引和所有标注；退出后保留检查点，重启恢复未完成任务，已暂停的任务保持暂停。
- 索引独立存放于应用数据目录 `cache/search/index.sqlite`。恢复标注备份后清除旧正文索引并关闭索引，需要重新主动启用；资料包不附带正文索引。
- 原生 SQLite FTS5 字符片段索引支持中文短语；一、二字查询使用子串匹配。引号、OR、符号按普通文本处理，不直接执行用户输入的查询语法。

## 读取及容量边界

每份文本读取前 **2 MiB**，超过上限的文件标记「部分内容」，无法搜索未读取的尾部。支持 UTF-8、带 BOM 的 UTF-16 和 GB18030；无法解码、二进制及容量失败显示原因，修复后可重建重试。正文和规范化文本合计预算 **64 MiB**；FTS、数据库与日志还有额外磁盘开销，此预算不是总磁盘或进程内存上限。

文件变化由现有目录监听、手动刷新及新增的有界轮询核对。正文轮询每约 5 秒核对最多 16 条支持格式记录，大资料库完整一轮需要更长时间；需要立即更新时点击左上角刷新，或对相关目录配置监听。核对修订变化后旧索引不再参与匹配，后台重新建立索引。

Office、PDF、HTML、图片及 OCR 暂不参加正文检索，仍保留已有预览和文件信息搜索。PDF 内容检索及 Office 检索沿后续 v0.5 系列推进。

## 安装与交付

推荐发送 `releases/v0.5.0/Shiqian-v0.5.0-Windows-x64-setup.exe`。升级前导出标注备份，关闭工作台和浮窗，安装时保留应用数据。应用标识和标注库 v2 格式保持兼容，正文索引是可重新生成的独立缓存。
