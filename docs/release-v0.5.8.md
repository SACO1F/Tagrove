# 拾签 v0.5.8：稳定与国际化收尾

本地 Windows x64 交付，内部版本 0.5.8，未上传 GitHub。默认主题仍为绿色，沿用现有文件整理、预览与搜索行为。

## 改进

- 动态操作提示、导入通知、确认对话框和浮窗状态使用文案键与参数；文件名、标签名和路径作为参数原样保留，主要通知可在显示期间切换语言。
- 补齐 AI 识别数量、审核结果、语义任务、路径修复、监听状态、资料包进度、导入/导出窗口和文件阅读提示的英文文案。日期与时间按所选语言显示。
- 英文服务/系统错误提供本地化解释与错误码，并保留原始诊断细节；历史操作、服务原文和用户正文不改写。
- 扩展文案构建检查：检查整个目录的占位符，以及通知/确认入口的未本地化字符串。新增结构化消息和错误信息测试。
- 继承六种主题色、文本选中颜色与列表/瀑布流/浮窗的独立标签配色。
- 新增英文使用说明及升级、交接、DPI、多屏和长期使用的验收记录。

## 使用与升级

先退出旧版，再运行新的独立 EXE；安装版可使用新安装包升级。不要删除用户资料目录。建议先在偏好设置导出标注备份，重要原文件另行备份。

标注备份不含原文件；跨电脑交接请导出资料包，在接收端导入到可写目录。资料包按原父文件夹名组织文件，中文和同名文件保留；导入前检查预览数量。详细说明见英文使用说明（历史资料，见 v0.6.12 源码快照）与交付验收（历史资料，见 v0.6.12 源码快照）。

## 边界

英文界面中的历史记录、模型生成的标签/解释、用户内容和原始诊断细节可能包含中文，这是原始数据，不自动翻译。Windows 系统对话框跟随系统语言。Office 预览仍侧重内容阅读，不承诺复杂排版完全还原。

测试与限制（历史资料，见 v0.6.12 源码快照）。双机实机交接、安装程序真实覆盖、多屏 DPI 与长期运行未完成时，不据此宣称全部实机验收通过。


## experience.1：筛选日期、侧栏高亮与主题色名称

最新本地交付目录 `releases/v0.5.8-experience.1`，内部版本仍为 0.5.8。

- 筛选日期改为应用内输入/日历，英文显示 YYYY-MM-DD 占位符、英文月份/星期，中文随语言切换。支持有效日期校验、闰日、月份/年份选择、键盘移动、清空和今天；不依赖 Windows 原生日历语言。结束日期取当地下一天零点，兼容夏令时。
- 标签索引的悬浮、键盘焦点及选中高亮覆盖整行，包含右侧重命名按钮；圆角内绘边线避免裁切。文件夹长名称规则不再依赖中文 aria-label。
- 六种主题色以“荷叶绿、群青、桔梗紫、海棠红、金叶黄、青灰”命名，参考[中国色](https://zhongguose.com/)。名称是灵感命名，现有主题 ID 和色值保持原样，不宣称等于该网站对应色值。
- 色点提示复用现有悬浮提示，显示名称、色块与当前基础 HEX，支持中英文及键盘聚焦；去掉系统原生 title，避免重复提示。
