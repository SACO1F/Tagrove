# 拾签 v0.4.4：预览增强

2026-10-11。本轮为本地开发交付，GitHub 公开下载仍为 RC.4，未上传 GitHub。

## 新增内容

- DOCX：内嵌 PNG／JPEG／WebP 图片、表格中的图片、常见项目符号及数字／字母／罗马数字列表。支持段落样式继承、编号起始覆盖与常见嵌套层级。列表复杂重启规则仍可能近似显示。
- 图片只缩小、不放大小图，最长边 1280 像素。最多 20 个不同图片引用，单图 4 MiB／8 百万像素，累计 24 百万解码像素／8 MiB PNG 输出；相同引用复用。外部图片与不支持格式显示占位及提示，保留文字。
- XLSX：常见日期／时间、固定小数、千分位、百分比和简单货币格式，兼容 1900／1904 日期系统。显示值与原始值分离，悬停查看原值及公式；复杂条件、会计、分数、累计时间等未支持格式回退原值并显示点线提示。
- 合并单元格范围在工具栏提示，仍按原单元格阅读，不还原合并布局与图表。
- DOCX／XLSX／CSV／TSV 卡片与详情增加按需文字摘要，最多 450 字符，按文件身份、版本及解析版本缓存。列表小图标不解析全文；失败保留类型图标。摘要不是页面缩略图。

## 使用与边界

选择 Office 文件，在详情点击「放大预览」或按 Space。工作表上方选择不同 Sheet，悬停单元格查看原始值和格式回退说明。摘要和预览都在本机生成，不触发 AI，也不请求外部图片。

继续保持内容阅读，不实现完整 Office 排版／编辑／公式计算。旧 DOC／XLS、PPT／PPTX、加密文档使用外部程序。现有文件与 XML 预算保留；新增单元格文字 4096 字符、累计文字 2 MiB 与格式代码 256 字符的预算，超出时截取或提示，防止共享字符串展开过大。无新增运行时依赖，无数据库结构迁移。

## 实现参考

编号覆盖遵循 [Open XML LevelOverride](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.wordprocessing.leveloverride?view=openxml-3.0.1) 的结构；单元格格式引用参考 [Open XML NumberingFormat](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.spreadsheet.numberingformat?view=openxml-2.8.1)。本版只实现其中明确列出的常见显示子集。
