# 拾签 v0.5.9：阅读体验与状态稳定

本地 Windows x64 交付。版本号 0.5.9；本轮没有上传 GitHub。

- 按文件保存图片缩放和画布位置、PDF 页／纵向页内位置、Word／文本滚动、Excel 工作表与滚动、HTML 模式和位置、Markdown 模式和位置、PPTX 内容页；切换、关闭详情和正常重启可恢复。
- 阅读状态使用资料库内的独立表，限制 500 条，保存合并写入并在正常退出前等待；不保存正文或密码，不进入资料包。
- 文件版本或身份变化后重置旧位置；搜索命中位置优先。阅读失败不显示前一文件内容。
- Markdown 在本次运行中保留未保存草稿，返回时恢复编辑模式；外部修改提示核对，冲突保存不覆盖原文件，重新读取需确认放弃草稿。
- 修正关闭被后台任务阻止时过早清空草稿的问题；放大预览保持只读，独立于详情中最后使用的编辑模式。

本轮先完成计划中的阅读状态基础，不包含 PDF 书签、Office 全排版、跨进程 Markdown 草稿恢复、OCR 或图片视觉检索。阅读上限和格式边界沿用既有说明。

先退出旧版，再使用本轮直接运行 EXE 或安装包升级；重要原文件另行备份，并先导出标注备份。旧版可忽略新增阅读表，资料包不迁移阅读位置。
