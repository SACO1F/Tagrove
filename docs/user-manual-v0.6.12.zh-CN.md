# 拾签使用说明

适用版本：v0.6.12 · Windows x64  
更新日期：2026-10-19

拾签通过多标签、备注和搜索管理本地图片与文件。文件通常保留在原来的位置，工作台保存它们的路径与标注。“标注”指添加标签、备注和整理信息，不是在图片上直接画线或圈选。

本轮默认主题为群青，已保存的个人颜色保留；工作台、浮窗与 Chrome 扩展统一使用透明 Tagrove Logo。正式发布下载：https://github.com/SACO1F/Tagrove/releases/tag/v0.6.12。

本版作为正式版发布；已验证范围为 Windows 11 x64，Windows 10 尚未完成同等验收。原生安装器未做商业代码签名。详细测试范围见 [验证说明](validation-v0.6.12.md)。

## 1. 安装、升级与启动

本轮本地交付目录为 `releases/v0.6.12/`，程序内部版本号为 `0.6.12`。

| 文件 | 用途 |
|---|---|
| `Shiqian-v0.6.12-Windows-x64.exe` | 直接运行程序，电脑需有 WebView2 运行环境 |
| `Shiqian-v0.6.12-Windows-x64-setup.exe` | 安装包，供自己或同事安装 |
| `Shiqian-v0.6.12-manual.zh-CN.md` | 本说明 |
| `SHA256SUMS.txt` | 交付文件的 SHA256 校验清单 |

升级前建议导出一份标注备份，并另行备份重要原文件。退出旧版后，再运行新 EXE 或安装新版本。安装向导如要求卸载旧版，请保留用户信息；不要选择删除资料库。避免两个版本同时写入同一资料库。

独立 EXE 不是把数据存到程序旁边的便携版。同一 Windows 用户运行新版时沿用原应用数据；只把 EXE 发给同事，不会把文件和标注一并带过去。跨电脑交接见第 10 节。

首次启动可配置 AI，也可暂不设置；随后显示简短使用引导。AI 是可选能力，不设置仍可导入、手工标注、预览和本地搜索。偏好设置可重新打开使用引导。

## 2. 工作台与文件选择

左侧提供全部资料、待整理、我的收藏、最近加入和需要关注。标签索引区分文件夹标签和普通标签，普通标签可按分类展开。

- 点击文件：选中并展开右侧详情；再次点击同一文件：取消选择并收拢详情。
- Ctrl＋点击：逐个加入或移出多选；Shift＋点击：连续选择。
- Ctrl＋A：全选当前结果／取消全选；超过批量上限时会提示缩小范围。
- 点击详情右上角叉号：关闭详情并取消选择，不会从资料库移除文件。

可拖动左侧分隔条调整菜单宽度；缩小到阈值后自动收起，也可用左上角按钮收拢／展开。详情左侧分隔条可调整详情宽度，双击恢复默认宽度。

瀑布流显示图片或文档卡片；列表显示名称、标签、修改时间、大小。悬浮卡片可查看文件名与标签；列表只有在标签显示不全时补充标签浮层。列表列边界靠近时显示调整手柄，可拖动改变列宽。窄窗口下文件区域可横向滚动。

瀑布流文件区 Ctrl＋滚轮调整列数：向上减少列数并放大卡片，向下增加列数。偏好设置可显示／隐藏整套列数调节组件；隐藏后快捷操作仍有效。

## 3. 导入文件

点击“加入文件”选择文件或文件夹，也可把文件／文件夹拖入工作台。文件夹导入会处理受支持的子目录项目；原文件通常留在原处。

启用文件夹自动标签后，新文件获得其**直接父文件夹名称**对应的标签。该标签与普通标签分区显示，不作为可固定到标签浮窗的普通标签。

导入完成后可能出现“生成语义索引？”提示。只有你确认并核对发送范围后才生成；错过提示仍可从任务面板查找导入批次。普通导入不等于已生成语义向量。

通过手工添加标签而带入工作台的文件不会因此自动提交 AI 识别。自动标注、语义索引和正文索引是不同功能，分别受其设置和确认流程控制。

## 4. 标签、分类、别名与备注

选中文件后，在右侧“标注”页签添加／移除标签，也可使用工作台右下方的“添加标签”按钮。选中多份文件时，可共同添加相同标签。

标签索引使用单选筛选；组合包含／排除条件请在筛选栏设置。鼠标悬浮或键盘聚焦标签行时，整行高亮包含右侧重命名按钮。点击编辑按钮或打开管理标签，可重命名、管理规范名称和别名、合并或删除标签；提交前阅读影响范围。

- 重命名会同步已有文件的标签显示，不会修改原文件名。
- 删除标签会移除标签关联；不会删除原文件，也不会清空文件备注。
- 合并前先看目标标签及影响预览；不能执行的按钮保持禁用。
- 分类用于组织普通标签，例如“学习”下放“数学”“语文”；分类名、标签名和别名属于用户数据，不随界面语言翻译。

备注保存在本机资料库并自动保存。看到“保存失败”时，先重试或检查原始错误；“重新读取备注”会以数据库已保存内容替换当前草稿，请先保留需要的文字。备注不同于 Markdown 文件正文。

## 5. 标签浮窗

从左下角打开标签浮窗。它支持调整大小、置顶开关、收起以及返回工作台。

2026-10-18 浮窗修正版默认显示全部普通标签，并在打开时展开分类；原有顺序保留，新标签自动加入。文件夹标签和未确认 AI 建议不显示。分类标题右键 →“重命名分类”可修改名称，归属不变；系统“未分类”不提供重命名。

- 将标签主体拖到工作台对应文件，或把本地文件拖进标签，为文件添加标签。
- 选中标签后，也可使用“选择文件标注”。
- 点击标签右侧九宫格打开管理操作；拖动九宫格调整顺序。查找标签时，先清空查找文字再排序。
- 可调整普通标签的分类归属和颜色；不同文件视图使用同一标签的配色。
- 右下角“添加标签”用于添加普通标签。已接受的普通 AI 标签会进入可用标签，不需要重复创建。
- 底部保留最近三步操作；显示撤销按钮时可撤销支持的当前操作，不能把它当作无限历史恢复。

浮窗底部控件保持固定，标签列表在上方滚动。不需要滚动时，滚动条及上下箭头隐藏。

## 6. 搜索、筛选和日期

点击“全部资料”旁的搜索图标，或按 Ctrl＋F 展开搜索栏。搜索结合文件信息、已完成索引的正文以及可选的语义补充；本地搜索在语义服务关闭或失败时仍可用。

文件信息包括名称、标签和备注。正文搜索需要启用对应索引；扫描图片、加密文件、不支持或超出索引范围的内容可能无法参与正文搜索。命中片段用于说明当前搜索匹配位置，不是完整文档预览。

点击“筛选”可组合搜索范围、文件类型、状态、包含／排除标签、匹配方式、目录和修改时间。用“保存筛选”给当前条件命名，在管理集合中维护；已保存集合横向显示在管理按钮右侧。

### 修改日期

日期框与右侧日历按钮位于同一边框内。支持两种输入方式：

1. 直接输入严格格式 `YYYY-MM-DD`，例如 `2026-10-17`。
2. 点击日历按钮，选择年份、月份和日期；也可用“今天”或“清除日期”。

英文界面显示 `YYYY-MM-DD`、英文月份与星期；中文界面显示中文提示。筛选日历由拾签提供，不依赖 Windows 原生日历语言。非法日期如 `2025-02-29` 会提示错误，在修正前不会写入新的筛选条件。

起始日从当地零点计算；结束日包含当天，内部边界为当地下一天零点，兼容夏令时变化。只填一侧表示单边时间范围，两侧清空则不限制日期。

键盘操作：Alt＋下方向键打开日期日历；日期网格中左右移动一天、上下移动一周，Home／End 到本周首尾，Enter 选中；Escape 关闭日历并返回按钮。

## 7. 文件详情和预览

右侧详情有“内容／标注／信息”三个页签。顶部图标用于打开原文件、放大预览和关闭详情；文件名一行右侧可在文件夹中显示、复制路径。

| 类型 | 当前用法与边界 |
|---|---|
| 图片 | 内置大图预览；Ctrl＋滚轮以鼠标位置为缩放中心 |
| PDF | 支持连续阅读与缩放；密码、损坏或超限时按提示处理 |
| Markdown | 阅读与源码编辑；“保存”或 Ctrl＋S 才写回原文件 |
| HTML | 静态预览／源码查看；原文件脚本不执行，外部资源可能受限 |
| Office 新旧格式 | 支持格式可用内容预览；本机引擎可用时切换原排版分页阅读，详见文末 v0.6.12 说明 |
| 其他格式 | 按界面提示使用原应用打开 |

在支持的预览区 Ctrl＋滚轮缩放；缩放选择器可选自动、实际大小、适合页面／宽度或比例。相同手势在文件卡片区用于调整瀑布流列数，请留意鼠标所在区域。

切换语言或主题不会主动保存／放弃 Markdown 草稿。关闭窗口遇到未保存提示时，确认要保留还是放弃；重要内容先保存。文件被外部软件修改后，重新检查状态；有冲突时核对原文件再重新读取。

## 8. AI 建议与语义检索

AI 标注与语义检索独立设置。AI 标注分析文件并提出标签建议；未确认建议带 AI 标记，不直接进入可重复添加的普通标签库。接受后移除待确认标记；拒绝后移除对应建议。

“AI 建议审核”包含待确认、操作记录、识别任务。提交前检查文件和标签范围；批量审核记录与撤销能力以界面提示为准。

语义检索需要兼容 Embeddings 的向量服务与向量模型，不能用对话模型替代。先核对服务地址、模型及密钥，再测试连接、预览生成范围并确认发送。远程服务可能计费；取消不保证已经发送的请求不计费。部分失败可在任务中明确选择范围重试。

关闭语义检索后不显示智能补充，本地名称／标签／备注及已启用的正文索引仍可工作。语义相似度不代表内容一定正确，打开原文件核对。

## 9. 外观与语言

在“偏好设置 → 外观”选择深浅／系统模式、主题色和界面语言。当前提供 12 种主题：群青（默认）、荷叶绿、桔梗紫、海棠红、金叶黄、青灰、青碧、赭石、黛蓝、朱红、苔黄绿、咖啡棕。各自适配浅深色，悬浮色点显示名称、色块和 HEX；已有个人选择保留。

主题色作用于工作台、浮窗、操作与选中状态；标签自行设置的颜色独立保留。文件格式图标和 HTML 原文件颜色不强制改成主题色。

中英文切换立即生效并在重启后保留。用户文件名、标签／分类／别名、备注、正文、历史记录和模型返回内容不自动翻译。英文错误可附解释和错误码，原始诊断仍保留。系统文件选择器仍随 Windows 语言。

## 10. 备份与发给同事

| 方式 | 包含什么 | 适合什么 |
|---|---|---|
| 标注备份 | 标注库及其支持的设置，不包含原文件 | 本机升级保护、资料库恢复 |
| 资料包 | 选定原文件及其支持的标签、备注、收藏等信息 | 跨电脑交接 |
| 安装包／EXE | 软件程序 | 给同事安装或更新，不包含你的资料 |

发给同事时：

1. 自己先导出标注备份，并确认原文件可读。
2. 在工作台选择要交接的文件，用导出资料包图标；核对交接范围和缺失项目后导出。
3. 把安装包和资料包分别发给同事。
4. 同事退出旧版并安装新版，保留用户信息；再选择“导入资料包”，指定已经存在、可写的接收目录，核对预览后确认。
5. 导入后检查文件数量、父文件夹分类、标签、备注、收藏及打开原文件是否正常；确认完成前保留资料包。

接收文件按原**直接父文件夹**分类，例如 Pic 与 Desktop，不复制发送者完整盘符目录树。同名文件采取独立命名避免静默覆盖；相同资料包重复导入有保护。路径变化可使用重新关联或路径修复，不要只复制数据库后假定另一台电脑路径相同。

恢复标注备份会替换当前标注库，按提示保护当前数据；它不能恢复已经丢失的原文件。服务密钥与机器／用户环境有关，换电脑可能需要重新配置。

## 11. 路径异常、后台任务与恢复

原文件移动、改名、磁盘离线或权限变化时，进入“需要关注”，或在信息中重新关联。批量路径修复先预览候选并确认；不要把不同文件误关联为同一份资料。

后台任务可查看导入、正文索引、AI、语义和资料包状态。失败时阅读错误码与原始细节；取消后先确认已完成部分和任务状态，不要重复无范围地提交。关闭程序如提示任务或保存尚未完成，先按提示处理。

需要反馈问题时，可导出诊断报告，发送前检查其中内容。不要发送密钥。真实覆盖安装、双机交接、多屏 DPI 和长时间运行的待验收项见[验证与待验收范围](validation-v0.6.12.md)。

## 阅读位置与编辑保护

选中文件、关闭详情、切换文件或正常重启后，自动恢复该文件保存的阅读状态：图片缩放及画布位置、PDF 页与纵向页内位置、Word／文本滚动位置、Excel 工作表及滚动位置、HTML 预览／源码模式、Markdown 阅读／编辑模式与位置，以及 PowerPoint 内容页。搜索命中定位优先于普通阅读恢复。

阅读状态只保存缩放、模式、页码和坐标，不包含正文或密码；本机资料库最多保留 500 条记录。它不作为资料包交接内容。原文件版本或身份变化后，旧位置失效，重新开始阅读；不会把旧位置强行套到新内容上。损坏和不支持格式保留错误提示，不展示前一文件内容。

Markdown 未保存草稿在本次运行中切换文件／关闭详情时继续保留。返回文件时恢复编辑模式；原文件外部变化时保留草稿并提示核对。保存冲突不会覆盖外部文件；“重新读取”需要明确放弃草稿。草稿不在本版作为可跨进程恢复的数据，关闭软件仍须保存或明确放弃。意外进程终止可能丢失未保存正文，重要修改及时 Ctrl＋S。

阅读状态写入失败时仍可阅读，界面会提示本次状态暂未保存并提供重试。正常退出前会等待已排队的状态写入；强制结束进程可能丢失最后一小段位置变化。Office 复杂排版和大图的原始像素保真范围沿用此前限制。


## 搜索命中来源

输入关键词后，卡片和列表会简要标出文件名、标签、别名、备注、正文或语义补充，悬浮查看详情。清空关键词会隐藏说明和正文片段。相关度排序中，完整别名比文件名中间的包含匹配更优先。


## 大资料库与恢复维护

在偏好设置打开诊断报告，可查看标注库、正文／语义索引、预览缓存占用，以及任务、阅读位置和恢复状态；报告不包含原文件名、路径、正文、标签名、服务地址或密钥，由你自行导出分享。

备份导出遇到已存在的文件名会拒绝覆盖，请选择新名字。标注备份不包含原文件；导入到另一台电脑请使用资料包。恢复前自动创建保护备份。旧备份恢复后可立即保存阅读位置；若上次恢复中断，下次启动会关闭服务配置、取消待发送 AI 任务、暂停目录监听并清理派生索引。确认资料后，按需重新启用目录监听、配置服务、建立正文和语义索引。

Fuse.js 只是开发计划中的候选，目前程序不含该功能。

## 浏览器采集：链接、摘录与图片

安装、更新和故障处理见 [扩展说明](../browser-extension/README.md)与[浏览器采集说明](../browser-extension/README.md)。配套桌面与扩展版本均为 0.6.12；扩展目前为中文、开发者模式手动加载。

在网页图片上右键“保存图片到拾签”，检查标题、来源页面与图片地址，再明确保存。支持公开 HTTP／HTTPS 的 PNG／JPEG／WebP／GIF／BMP，单图最多 50 MiB、1 亿像素；保存原始下载字节，正常显示图片卡片和本地大图。信息页记录来源页、原／最终图片地址、采集时间、尺寸及 SHA256。右键只生成草稿，不自动采集；也可手动选择“网页图片”并填地址。

图片预览按钮主动触发匿名浏览器请求，可能被跨域策略限制；预览失败时仍可核对地址并尝试桌面保存。下载不带浏览器 Cookie、授权或代理，不支持登录、内网、SVG、blob／data、整站采集。需要登录的图片可先在浏览器保存到本地，再从失败任务选择已下载原图以保留来源和标签。未选标签的新采集在桌面 AI 自动标注启用时自动排队，建议需确认；不生成来源文件夹标签。

链接保存来源，不下载整页；摘录保存最多 20,000 字符纯文本，标题最多 300 字符。独立草稿最多 20 份／24 小时。普通文本框选区可采集，密码框除外；受保护网页与跨域框架可能限制读取。

桌面关闭时队列只保存图片地址与文本信息，不保存图片字节。重新运行桌面后重试，只有确认才算入库；临时地址失效可能需要重新采集。队列最多 200 项，不淘汰未完成任务；保留原扩展目录与 profile，更新后重新加载，不要卸载或清空队列。相同图片内容复用已有记录，不覆盖首次来源与标注。移动 EXE 后在偏好设置修复连接；断开／移除连接不删除资料及队列。


## 完成内容

- 网页资料在右侧详情与放大预览中提供“阅读／编辑／原始采集”。阅读副本可修改标题和纯文本正文；原始标题、摘录、来源 URL、采集时间及采集去重依据保持不变。
- 明确点击保存或 Ctrl＋S 提交；标题最多 300 字符，正文最多 20,000 字符。未保存草稿在本次运行中切换文件后保留，退出前提示处理；不承诺异常退出后的草稿恢复。
- 多窗口或其他整理操作导致版本变化时拒绝覆盖，保留草稿；可明确重新读取最新内容。恢复原始采集需确认，保存和恢复均支持会话内撤销。
- 修改后的标题和正文立即参加普通搜索；正文索引开启后自动重新索引。旧索引与当前修订不符时不会继续展示旧片段。阅读中高亮当前搜索词，可跳转下一处命中。
- 筛选栏支持按来源网站完整域名及网页链接／文字摘录／网页图片筛选，并可保存为集合。域名为精确匹配，不自动包含子域；填写域名后按 Enter 或移开焦点应用。
- 筛选后可 Ctrl＋A 选择结果，在批量标注中统一整理标签；标签选择支持规范名及别名，全部已有的标签不重复列出。

## 升级和交接

先使用旧版导出标注备份并备份重要原件。资料库升级为 schema 7；schema 6 升级前生成 `backups/before-preview-image-schema-v6.sqlite`。旧版不能直接打开新版库；不要降级覆盖新库。

网页图片资料包使用格式 7，接收方需 v0.6.12；阅读副本包格式 6，链接／摘录包格式 4，普通本地文件包格式 3。原始采集和阅读副本随标注备份保留，但备份不含原件；跨电脑请用资料包。

保存阅读副本会在应用管理目录写入新描述文件，再以事务更新资料记录；失败不替换旧记录。用于会话撤销的旧描述文件暂保留，不要手工清理 `captures`。阅读副本模式以纯文本显示，不执行脚本，不下载整页，不新增 AI 请求；“在线网页”是单独的联网浏览模式。

Chrome 扩展版本同步为 0.6.12，协议和权限保持不变。更新扩展仍保留原目录与 Chrome 配置，替换后重新加载；移动 EXE 后修复连接。网页图片继续限公开 HTTP／HTTPS；本轮扩展为 PNG／JPEG／WebP／GIF／BMP、50 MiB／1 亿像素。



## v0.6.12：本机引擎、原排版与在线网页

选中文档 → 内容 → 原排版。程序按文档类型检测 Microsoft Office、WPS Office、LibreOffice，默认按这个顺序选择；可在“预览引擎”中切换。已选引擎同类程序正在运行时，请关闭它或使用其他引擎；拾签不会关闭用户文档。需要缺失组件时点击“按需安装增强预览组件”，在官方页面自行安装 LibreOffice，再点“检测引擎”；也可继续使用支持格式的轻量内容预览。

DOC／DOCX、XLS／XLSX、PPT／PPTX 共享原排版 PDF 阅读；旧格式内容模式通过临时新格式副本读取。Excel 内容模式可切换工作表，原排版按文件保存的打印设置分页，两者用途不同。单个源文件及转换结果各最多 64 MiB；内容解析仍有原有 32 MiB 与行列截取限制。转换最长等待 90 秒；激活、受保护视图、密码或超时情况下，请检查办公软件提示、换引擎或直接打开原件。转换不是编辑原文件，也不是 Office 动画播放或 SmartArt 编辑。

PDF 现在可以直接拖选已有文本并复制；扫描 PDF 若无文字层仍不可选。本轮不做 OCR。原排版效果取决于引擎、字体和文档特性，复杂 SmartArt 和 WPS／LibreOffice 尚待对应机器验收。

网页资料 → 内容，默认联网打开来源网页。可后退、前进、刷新，当前地址位于按钮下方；外部打开会交给系统浏览器。在线视图使用独立登录环境，不共享 Chrome Cookie；下载和新窗口关闭，不是离线归档。返回“阅读副本”或切换文件会关闭在线视图。原始摘录、副本编辑、搜索和保存仍按上文操作。

新增 GIF／BMP 采集和普通导入。GIF 预览为首帧；单图 50 MiB、1 亿像素，较大图片会使用更多内存。登录图片、私网、SVG、blob／data 尚不支持。扩展须同步更新为 v0.6.12。


## v0.6.12：采集标签与在线预览修复

打开普通网页，点击扩展，或右键保存链接、选中文字、图片。核对标题、来源和类型，在标签区搜索并勾选已有普通标签，再点击保存。标签可多选；文件夹标签和未确认 AI 标签不会列出。未开启 AI 也可以手动选标签。

目录缓存可在离线状态显示，但保存任务需桌面连接后才能完成。搜索返回最多 500 个匹配标签，每次最多选择 50 个。标签被重命名时刷新目录；被删除时队列显示不可用原因，点击“重新编辑”修改后再次保存。重新编辑会替换未完成任务，不复用旧请求 ID。

网页链接尽力截取可读取正文，最多 12,000 字符；权限不足或无法读取时仍保存标题和链接。摘要是阅读副本，可在桌面编辑；不等同于完整 HTML 或整个站点下载。摘录最多 20,000 字符，图片维持公开 HTTP／HTTPS、PNG/JPEG/WebP/GIF/BMP、50 MiB／1 亿像素上限。

## 自动 AI 建议

未选择标签且桌面 AI 自动标注启用、服务配置可用时，新采集自动排队。链接使用正文摘要或标题 URL；摘录使用文字；图片使用图像。内容会发送到用户配置的模型服务，可能计费。手动选择的标签不被覆盖，AI 新建议带 AI 标识，确认后才成为普通标签。关闭 AI 时只保存，不请求服务。重复采集补充手动标签，不重复启动识别。旧记录按需手动识别。

## 在线查看

打开网页资料的右侧内容页或放大预览时，默认加载来源网站；切换到阅读副本可阅读本地文字。支持前进、后退、刷新和外部打开；返回阅读副本、关闭详情或切换文件时关闭原生网页视图。详情与放大预览切换后恢复有效视图，不被过期会话误关闭。

已实际核对 [正则教程](https://deerchao.cn/tutorials/regex/regex.htm#testing) 在两种位置显示。独立 WebView2 不共享 Chrome 登录状态，不允许网站调用本地资料库接口、打开新窗口或下载文件。网站网络、证书及脚本兼容问题仍可能存在；本地 HTML 文件使用原有静态／源码入口。

数据库仍为 schema 7；图片资料包格式 7，阅读副本包格式 6，链接／摘录无副本格式 4，普通文件格式 3。不要手动删除 captures 文件夹。跨电脑使用资料包，标注备份不含原件。完整说明见 [使用说明](user-manual-v0.6.12.zh-CN.md)。


## v0.6.12：插件弹窗与预览工具

右键“保存到拾签”改为在浏览器右上角打开原生扩展弹窗，不新开页面。建议固定拾签到工具栏；需要 Chrome 127 或更新版本以支持直接唤起。无法自动打开时，草稿仍保留，拾签图标显示提示，点击图标继续。扩展内容采用大圆角；弹窗外框由 Chrome 绘制。

在线网页、原排版位于各自工具栏最左侧，与阅读／编辑按钮保持相同的尺寸、胶囊形态和动效，并带小图标。Office 默认进入原排版并检测引擎，原排版模式显示引擎选择和检测按钮；返回内容预览后隐藏引擎工具。旧 Office 沿用可用引擎预览路径。

PDF、图片、Office 原排版及流式内容首次阅读默认“适合页面”；已经保存的用户缩放选择保持不变。流式 Markdown、HTML、网页副本和 Office 内容按可用阅读宽度重排，不将整份长文缩成一张图。在线网页仍由网页自身响应式布局适配，不等同于 PDF 页缩放。

Microsoft／WPS 的 Excel PDF 原排版在隔离的只读工作簿中开启打印网格线，不保存回原文件。显式边框与原有样式继续由 Office 渲染；LibreOffice 保留源文件打印设置，兼容性需实机验收。更新缓存版本后重新生成，避免继续使用不带网格线的旧 PDF。

原排版检测阶段不显示动画，实际转换显示居中的固定画框和柔和扫光占位，不显示虚构百分比；完成后显示真实 PDF。减少动态效果设置下停用扫光。原文件转换失败时仍显示错误、重试和外部打开入口。


## v0.6.12：默认预览与阅读副本

网页默认在线网页，Office 默认原排版；图片、PDF、本地 HTML、Markdown 沿用对应阅读器，首次缩放仍为适合页面。打开在线网页会访问来源站点，使用独立 WebView2 登录环境，不共享 Chrome Cookie。切换阅读副本关闭在线视图；保存副本不会跳回在线网页。

引擎检测阶段隐藏加载画框与扫光，检测仍正常进行；已有预览时重新检测不会清空预览。只有真正生成 PDF 原排版时显示画框、状态文字和扫光，三者作为一组居中于内容区域。

| 按钮 | 作用 | 会修改什么 |
|---|---|---|
| 阅读 | 显示当前本地文字副本；没有副本时使用原始标题和摘录 | 不修改 |
| 编辑 | 修改副本标题和正文，明确保存后更新 | 仅拾签管理的本地副本，不修改网站 |
| 原始采集 | 查看最初保存的标题、摘录与来源，便于对照 | 不修改，不会撤销编辑 |

“原始采集”是只读对照；“恢复原始采集”是另一个需要确认的操作，会移除已保存副本。网页链接最初可能只有标题和 URL；扩展采集的正文摘要保存在阅读副本中，因此原始采集不一定有完整正文。二者都不是完整离线网页。


## v0.6.12：标签建议边界与阅读间距

文件夹标签不发送到 AI 候选池；返回结果中的文件夹标签 ID、名称会被过滤，写入阶段再次校验。普通标签与目录结构保持区分，文件夹标签不计入 AI 候选池 1000 项上限。

浏览器保存链接、摘录或图片时，只要选择了已有标签，就只保存并添加所选标签，不自动排 AI。未选择标签时沿用 AI 开关；AI 关闭时仍不发送请求。重复采集已存在资料并补选标签时，会取消仍在排队／运行的自动识别结果接收；已经发出的服务请求可能仍被计费。已完成建议不会因重复采集被自动清除；显式点击 AI 识别仍可按需执行。

阅读副本的工具栏分隔线与下方网页链接类型、来源内容之间保留 20px 留白，阅读／编辑／原始采集共用这一间距。原有在线默认模式和副本保存行为保持。

## 保存失败与诊断（v0.6.12）

保存失败时，扩展弹窗和采集队列显示失败环节、错误代码、经过脱敏的具体原因和处理建议。图片服务器返回 HTTP 状态时，保留状态码：例如 403 为拒绝访问，404 为资源不存在，429 为访问频率限制；DNS 解析失败、下载超时、格式错误、图片超限、标签失效、连接异常和本地写入失败分别显示。

“已暂存到浏览器队列”只表示浏览器保留了任务，尚未确认保存到桌面。内容校验失败或浏览器队列写入失败时，应保留当前输入，按提示修正后再提交。临时错误仍按原规则自动重试；地址、格式、标签等需要人工处理的问题，在队列中使用“重新编辑”。不会因为诊断而自动清空任务。

点击“技术详情（已脱敏）”可查看错误时间、请求 ID、采集类型、尝试次数、本次耗时、扩展版本、已获取的桌面版本及来源站点。桌面版本无法获取时明确显示“尚未获取”。点击“复制诊断报告”，将报告连同复现步骤发给开发者即可；建议同时说明当时保存网页、摘录还是图片，以及能否在浏览器直接打开原图。

报告不附带网页正文、标题、完整链接及本机路径，并对常见凭据字段脱敏；分享前仍应检查剩余内容。诊断保存在本机浏览器队列，不自动上传。旧失败记录如果没有底层原因，会注明“旧记录未保留底层原因”，重试后更新诊断；成功后清除本项旧错误。浏览器或桌面未提供的信息不会凭空补造。

## 图片服务器返回 403 时（v0.6.12）

403 表示服务器拒绝此次访问；仅凭状态码不能确定是否需要登录，也不能保证更换请求头后就能下载。新版先按原方式请求；遇到 403 且可以安全发送来源时，增加一次来源站点兼容重试。Referer 只包含来源站点，不包含页面路径、查询参数或片段；HTTPS 来源不向 HTTP 图片发送来源信息。所有图片目标和重定向继续检查公网地址，下载不携带 Chrome Cookie、登录信息或授权字段。

如果兼容重试仍失败：

1. 在扩展打开“采集队列”，找到失败的图片任务，点击“打开来源网页”。
2. 在浏览器使用网站提供的下载入口，或将对应图片另存到本机。需要登录的网站请在浏览器正常完成登录；拾签不读取登录凭据。
3. 回到采集队列，点击“选择已下载原图”。拾签会打开本机文件选择窗口，请选择对应图片。
4. 拾签校验实际图片内容、格式、体积和尺寸后入库，保留这条任务的网页来源、原图片地址、标题和标签。选择的原文件保持原样，资料库保存副本。

支持 PNG、JPEG、WebP、GIF、BMP，不超过 50 MiB、1 亿像素。请自行确认选择的文件对应此网页图片；软件不宣称能验证它与被拒绝的远端原图完全一致。取消选择不删除任务；选错格式或文件不可读会显示原因，可以再次选择。窗口打开期间工作台及连接服务仍可响应，队列自动查询结果；关闭队列后可重新打开继续查询。重试成功清除旧错误，使用同一请求标识避免重复入库。桌面重启后，如果资料已入库，可从回执恢复成功状态。

本轮需要桌面端与扩展均更新为 v0.6.12。未增加 Chrome 网站访问、Cookie 或下载权限。使用新 EXE 路径后在桌面偏好设置修复浏览器连接；原扩展目录覆盖并重新加载，保留旧队列。已有 403 任务也可直接使用原图补救，无需删除重建。若想重新尝试新版网络下载，可在“重新编辑”中核对地址后保存。
