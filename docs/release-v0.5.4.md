# 拾签 v0.5.4：标签别名与查找整理

2026-10-13。本地 Windows x64 交付。本轮没有上传 GitHub。

## 新功能

- 普通标签增加规范名称和最多 20 个别名。在「管理标签」中点击链条图标，填写别名，每行一个；先预览文件、集合引用和名称冲突，再确认修改。
- 搜索名称、标签或备注时可以命中别名；手工输入别名会使用同一标签 ID，文件与标签浮窗显示规范名称，不重复创建同义标签。浮窗查找及添加标签列表支持别名匹配。
- AI 标签池包含别名；模型返回规范名称或别名均归到已有标签，多种叫法的重复建议会去重。此功能不增加模型调用，也不自动启用 AI。
- 重命名保留其余别名；将一个自己的别名改为规范名称时，移除重复别名。合并将源规范名称和别名转为目标别名；删除同步移除别名。支持现有会话撤销与冲突保护。
- 文件夹标签不设置别名；未经确认的 AI 新标签不进入别名管理。已确认 AI 标签编辑后转为普通标签。
- 保存的筛选集合支持改名、编辑搜索文字／范围、目录、递归及包含／排除标签条件；可用工作台当前条件替换完整筛选。类型、时间、状态、排序等未编辑的条件保留，提供摘要核对。管理集合支持上移／下移排序，多窗口发生变化时阻止旧数据覆盖。
- 应用带目录条件的集合前显示本机路径核对界面。资料包不传递筛选集合；集合随标注备份保留，跨电脑恢复后应核对目录。

## 数据与版本兼容

资料库从 schema 2 升级为 schema 3。首次升级之前自动保存 `数据目录/backups/before-tag-aliases-schema-v2.sqlite`，旧文件记录、标签关联和设置保留。升级后的资料库需要 v0.5.4 或后续支持 schema 3 的程序；请关闭旧版再运行新版。

标注备份格式仍为 1，清单 schema_version 升为 3，包含别名和集合顺序。新版可以恢复 schema 1／2 的旧备份并迁移；旧程序不能恢复新备份。备份仍不含原文件、AI 密钥或启用 AI 的授权。

新导出的资料包为 format 3，包含标签别名与原直接父文件夹分组。新版继续读取 format 1／2；接收新资料包的同事需要升级到 v0.5.4。导入预览显示别名冲突；提交重新校验，冲突时不会写入文件记录或标签，也不会留下本次暂存副本。

别名没有独立的文件关联，也不用于重写历史审核记录。文件夹名称可以与普通标签别名相同，文件夹自动标签仍按目录生成。每个标签的规范名称和别名在普通标签命名空间中不可歧义。

## 使用示例

规范标签「参考资料」设置别名「学习资料」与「Learning resources」。搜索任一别名都能找到关联文件；给文件添加「学习资料」时，文件只显示「参考资料」。如果另一个普通标签已经使用「学习资料」，预览显示冲突，确认按钮不可用，可先合并标签。
