# 拾签 v0.5.3：AI 建议批量审核

2026-10-12。本地开发交付；GitHub 公开下载仍为 RC.4，本轮未上传。

## 本版功能

- 左侧菜单新增「AI 建议审核」，集中查看待确认建议、操作记录和识别任务。文件按组显示缩略图、名称、建议标签、内容依据、来源模型与生成时间；支持搜索和分页。
- 选择本页或逐项勾选建议，每批最多 200 项；跨页选择保留。接受／拒绝先显示具体更改，再确认提交。
- 提交再次校验文件标注版本、标签版本、建议内容与原文件修订。任一项冲突时整批不写入，逐项显示原因；重新选择和预览后再提交。重复点击不会重复执行。
- 接受移除 AI 标记并将普通标签加入标签浮窗。拒绝仅移除所选未确认建议，并清理没有其他关联的 AI 标签。手工、文件夹及已确认标签保留。
- 最近批量审核记录持久保存，显示执行时的文件／标签名称、依据、模型和生成时间。记录、关联修改及浮窗同步在同一事务提交；记录失败则全部回滚。
- 识别任务页显示等待、处理中、失败和不支持计数，提供失败重试确认与取消全部识别。未启用 AI 时不发送请求，已有建议仍可审核，普通搜索与手工标注继续可用。

## 本轮体验更新

2026-10-13 更新：三个页签采用普通共享滑块，240 毫秒缓进缓出平移，没有拉伸、回弹或额外投影。连续点击从当前位置继续，支持方向键及 Home／End；减少动态效果时立即定位。内容保留轻微淡入。

修复窄窗口中右上角关闭按钮被裁切：移除工作台 960px 的 CSS 最小内容宽度，让工作台跟随窗口可用宽度；窗口控制区域保留 138px，最小化／最大化／关闭各保留 46px，不随其他内容压缩。原生窗口最小尺寸设置保持不变。

操作记录参考 [Branched Menu](https://reactbits.dev/c/micro/branched-menu) 的主干／分支关系。点击「接受／拒绝 n 个建议」时，明细沿分支依次展开；展开 280 毫秒、收起 200 毫秒，条目错开间隔 24 毫秒、总延迟最多 96 毫秒。箭头随状态转动，重复点击可中断并反向继续。没有新增动画库；减少动态效果时直接开合。

管理标签使用固定列布局，文件数量和合并／导出／删除按钮上下对齐。文件夹标签及没有其他普通目标可合并的标签保留合并按钮，但置灰不可点击。

工作台操作提示参考 [Swipe Toast](https://reactbits.dev/c/micro/swipe-toast)，在工作台顶部标题与加入文件按钮之间居中堆叠，最多三条。每条独立停留 5 秒，显示剩余时间细线，支持向下滑动或点击关闭；关闭时向上浮动并淡出，过渡约 160 毫秒。提示不是持久审计记录。

标签浮窗最近三步记录增加小型撤销按钮。每个可撤销步骤使用原生会话唯一身份校验；只有当前撤销栈顶部对应记录可点击，其余置灰，避免误撤销之后的工作台操作。撤销较新步骤后可继续撤销较早步骤；原有版本冲突保护继续有效。已撤销记录标为「已撤销」，重启后旧会话记录不可撤销。加入浮窗预设、导出等原本没有撤销的操作同样置灰，不移动或删除原文件。

三个页签保持同样的窗口和内容区尺寸，默认窗口高度 740 像素，小屏按视口的 90% 收缩。标题、页签和底部操作区域固定，长内容内部滚动。

待确认页的「已选 0 / 200、清除选择、拒绝所选、接受所选」固定在底部白色圆角操作栏内，按钮间距 12 像素，操作栏与窗口底部留出 24 像素；窄屏自动分行。深色主题使用对应的面板底色。识别任务页的「重试失败任务、取消全部识别、AI 设置」固定在右下角。

本次沿用 v0.5.3 版本号，最新更新包放在 `releases/v0.5.3-experience.12`。关闭正在使用的工作台及标签浮窗后运行新安装器，并保留应用数据。

## 如何使用

1. 偏好设置配置并启用 AI，导入支持的文件或在详情中重新识别。
2. 左侧菜单 → AI 建议审核 → 待确认，查看建议依据，勾选需要处理的项目。
3. 点击「接受所选」或「拒绝所选」，核对预览后点击「确认提交」。冲突时清除选择、刷新并重新预览。
4. 在「操作记录」展开某批查看详情。在「识别任务」检查失败并确认重试。

## 范围与费用

| 项目 | 本版范围 |
| --- | --- |
| 审核列表 | 每页 40 个文件，每批最多 200 个建议 |
| 历史记录 | 最近 50 批，达到 6 MiB 时提前清理最旧记录 |
| 请求并发 | 串行，每个文件一次请求 |
| 手动加入识别 | 每次最多 1000 个文件 |
| 建议输出 | 每个文件最多 5 个标签，每条依据最多 500 字符 |
| 内容输入 | 正文最多 12,000 字符；图片预览编码后最多 12 MiB |
| AI 源文件 | PDF 10 MiB，Office 30 MiB；与本地正文索引上限不同 |
| 请求超时 | 连接 10 秒，完整请求 90 秒 |

这些是数量与读取上限，不是金额、每日额度或模型 token 硬限额。实际费用由配置的模型服务计算；重试会重新发送请求。取消后丢弃结果，已经发送的请求仍可能计费。打开审核页和接受／拒绝建议均为本地操作，不调用模型。

批量审核没有撤销，也不提供跨会话撤销。请在预览中核对后提交；已有详情页的单项确认及工作台会话内撤销规则继续保留。操作记录仅覆盖此批量入口，不能替代全局审计日志。

## experience.14：Office 保存后刷新与标签索引

- 修复 Office 编辑器以临时文件替换原文件保存时，刷新误报“原位置已被另一文件占用”的问题。同一路径的活动 Office 记录验证对应容器格式后，更新文件身份、大小、时间与修订，保留标签及标注版本。重新导入同一路径也采用相同规则。
- DOCX、XLSX、PPTX 验证 ZIP 内对应文档入口及内容类型入口；旧 DOC、XLS、PPT 验证 OLE 容器签名。此规则将同一路径、同格式的 Office 文档视作更新，无法区分用户主动覆盖的另一份同格式文档。非 Office 或格式不匹配的替换继续要求重新关联。
