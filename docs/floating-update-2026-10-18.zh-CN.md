# 标签浮窗修正 · 2026-10-18

应用版本沿用 v0.6.11，交付目录单独标识 `v0.6.11-floating.1`。保留此前 O4 recovery candidate 和完整回退资料。

## 本轮改动

1. 浮窗默认显示所有可用的普通标签。旧 `floatingTags` 作为排序依据，自动补齐缺少的普通标签、移除失效和重复 ID，并保存完整顺序。之后创建的普通标签也会加入。文件夹标签与尚未确认的 AI 建议继续排除。
2. 每次打开浮窗默认展开分类；本次打开期间仍可手动收起分类。工作台的分类展开偏好不受影响。移除与“显示全部”冲突的“从浮窗移除”菜单项，删除标签仍使用原有确认流程。
3. 分类标题右键 → 重命名分类 → 输入新名字并保存。复用原有带版本检查的分类接口，分类 ID 和成员归属不变；未分类属于系统分组，不提供重命名。中英文界面均补充对应文案。
4. 标题栏名称允许收缩和省略，为操作按钮保留固定宽度。Windows 收起 / 展开时先解除不可调整状态，再设置当前最小尺寸与目标高度；收起后重新确认 64 逻辑像素高度。

## 对最小尺寸问题的核对

本机旧版在 280×320、中文默认设置下可以收起，因此没有记录成稳定复现了用户的故障。新版从窗口约束切换和标题栏挤压两方面处理，使用真实 EXE 检查最窄尺寸、最大字号、中英文反复点击收起和展开。

本轮新增旧稀疏排序迁移、后来新增标签、文件夹 / 未确认 AI 排除和重启持久化回归。两项旧断言依赖“只显示被选中的快捷标签”，已按新需求更新；失败标注仍不得改变文件关系的断言保留。

实际构建、核心测试和桌面回归结果以交付目录 BUILD-IDENTITY 和 evidence 日志为准。窗口原生拖拽手势及第二台机器的最小尺寸体验，仍建议按用户原先触发方式复查。

本轮结果：前端本地化检查、TypeScript 和生产构建通过；核心测试 212 通过、0 失败、3 忽略。实际 EXE 在 280×320、字体 16、中英文各三次收起 / 展开通过，收起高度 64；默认全标签、分类展开、右键重命名和重启保持通过，无页面异常。已检查最小尺寸截图。NSIS 安装包载荷与该实测 EXE 逐字节一致；本轮未重新执行安装 / 覆盖升级。
