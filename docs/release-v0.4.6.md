# 拾签 v0.4.6：受控文件夹监听

2026-10-12。本轮本地开发交付，公开下载仍为 RC.4，未上传 GitHub。

## 新增内容

偏好设置的「文件位置」新增「管理监听目录」。指定目录、递归范围和忽略规则，符合规则的现有及新增文件稳定后自动加入工作台。

- 后台轮询约每 5 秒检查；连续两次版本相同且间隔至少 3 秒后加入。分批最多 64 个候选，单后台线程；其他导入、资料包或路径修复繁忙时暂缓。重复检查不产生重复记录，工作台手动移除的文件不被自动恢复。
- 支持暂停、恢复、重新扫描、编辑和移除规则。暂停／移除只停止后续监听，文件和标注保留。状态显示待处理、加入、改名、内容更新、缺失和最近检查；后台任务提供摘要与管理入口。
- 同目录范围内唯一且身份／版本一致的改名或移动自动更新引用，保留标签、备注、收藏。删除与离线保留记录，恢复后补扫；替换、歧义或超出规则范围时提示路径修复。
- 监听 AI 默认关闭，仅显式允许且全局启用时给新加入文件排队；手工标注先导入的已有文件不补排 AI。暂停不取消此前已排队任务。
- 规则与暂停状态保存在本机；退出后停止，下次启动补扫。恢复标注备份后所有规则暂停；其他电脑或数据目录的配置先暂停，需核对后恢复。

## 范围与交付

最多 8 个互不重叠目录；单目录每次 20,000 条目／32 层。忽略规则最多 64 条、每条 128 字，支持大小写不敏感的 *／?，匹配相对路径或名称。隐藏、系统、链接和应用数据目录排除。

稳定等待是启发式，不承诺瞬时导入或识别长时间停顿的写入。自动路径更新不新增会话撤销。整体换盘前先暂停 → 路径修复 → 编辑目录 → 恢复；不同身份的副本会作为新增导入。

不新增运行时依赖，不迁移数据库。真实拔盘、网络盘、休眠、多屏及长时间稳定性继续按实机清单补证据；大规模性能基准安排在 v0.4.7。
