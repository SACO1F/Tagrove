# 拾签 v0.3.0-rc.3：图标与标签尺寸稳定

日期：2026-10-11。Windows 11 x64 候选修复交付。

## 本轮修复

RC.2 卡片动画会同时缩放内部图标、标签和文字。文档卡片包含固定高度的名称区域，横纵缩放比例不同，Markdown 图标因此显得忽宽忽窄，标签也随选择/取消而变大变小。

RC.3 保留图片与卡片的 300ms 缓进缓出过渡，为内部固定尺寸的 UI 同步抵消外层缩放。Markdown 图标保持正常宽高比，标签文字与标签按钮保持正常尺寸，文件名、扩展名及状态/选择/收藏标记同样保持尺寸。对应动画使用同一时间线，展开和收回均处理；不覆盖已有悬停、勾选和标签到达动效。减少动态效果模式仍跳过缩放动画。

资料包沿用 RC.2 的 v2 原父目录分类与旧 v1 读取兼容。交接双方应使用 RC.2 或后续支持 v2 的版本；已导入数字目录仍不会自动搬动。
