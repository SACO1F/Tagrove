# v0.6.2 图片采集

交付日期：2026-10-16。本轮为本地开发交付，尚未上传 GitHub。

## 本轮完成

Chrome 扩展支持右键图片，检查标题、来源页面和图片地址后明确提交。桌面下载并保存原件，正常显示缩略图与大图；信息页可查看来源页面、原图片／最终地址、时间、尺寸与 SHA256，并打开来源页面。PNG、JPEG、WebP，最多 16 MiB、4,000 万像素。

图片请求沿用独立草稿、持久队列和逐项重试。桌面离线时只排队地址与元信息，启动后重试；相同请求和相同图片内容去重，保留首次采集信息。图片不会自动进入 AI 识别，也不会生成网页目录标签。

下载仅允许公开 HTTP／HTTPS，检查 DNS 与每次重定向，不携带浏览器登录信息，不使用代理。网络处理在资料库锁之外，避免下载期间锁住整理操作。实际图片内容、MIME、尺寸与摘要均验证。

## 升级与交接

数据库升级到 schema 5，旧 v0.6.1 不能直接打开升级后的库。请在旧版先导出标注备份，并备份重要原件。已有 schema 4 库升级前自动保存 `backups/before-image-capture-schema-v4.sqlite`；此保护快照不应替代个人备份。

含采集图片的资料包为格式 5，需要接收方 v0.6.2；纯链接／摘录包仍为格式 4，普通文件包仍为格式 3。旧备份和旧包可导入新版。标注备份包含图片来源，不包含图片原件；跨电脑请用资料包。恢复标注备份不自动下载图片，已存在的原件继续关联。

外部修改采集原件后，导出会拒绝摘要不符的图片；重新关联需要与采集摘要一致的原件。同图重复采集不覆盖第一次保存的标题、来源、备注、标签或收藏。

## 使用和限制

更新扩展时保留原目录及 Chrome 配置，替换文件后重新加载，核对版本 0.6.2；独立 EXE 移动后修复本机连接。图片预览需手动点击，浏览器跨域限制可能令预览失败，桌面下载结果以提交后的反馈为准。

不支持登录图片、内网图片、SVG／GIF、blob／data、整站抓取、自动截图或整页离线。扩展界面目前为中文。干净系统安装、企业策略、物理双机与长时间运行仍待人工验收。
