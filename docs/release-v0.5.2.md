# 拾签 v0.5.2：PDF 正文检索与页码定位

2026-10-12。本地开发交付；公开 GitHub 下载仍为 RC.4，本轮未上传。

## 本版功能

- 「文件内容」搜索新增可提取文字的 PDF，返回命中片段与实际页码。与 TXT／Markdown／Office 共用主动启用的本地正文索引，无需 AI、联网、安装 Adobe 或完整 Office 引擎。
- 打开命中文件的放大预览，PDF 阅读器自动跳到命中页；手动翻页后可点击「返回命中页」。定位到页面，不标记 PDF 画布中的具体文字坐标。
- 扫描或无法解码的无文字 PDF 显示 `PDF_NO_TEXT`；加密、损坏、源文件超过范围分别显示明确失败原因。部分预定义中文字体编码（例如 UniGB-UCS2-H）不支持，显示 `PDF_FONT_UNSUPPORTED`，不会误称为扫描件。混合扫描与文字页可搜索已提取文字的页，覆盖说明显示无文字页数。
- 提取范围可检查。到达页数、单页正文、总正文或页面间耗时范围时标记「部分内容」；范围以外无法搜索，不执行 OCR。
- 原生后台逐页提取，与前台标注连接分离；页面之间核对暂停／取消／重建的任务代次，停止后不提交旧任务结果。文件更新后核对身份与修订，旧结果退出检索并重新提取。
- 保留 v0.5.1 的图标、列表全列显示、隐藏式列宽调整、清空搜索与标签浮层修复。

## 如何使用

1. 将 PDF 加入拾签；偏好设置 → 正文索引 → 启用索引。仅处理已加入的支持格式，不扫描全盘。
2. 展开搜索，切换「文件内容」，输入正文中的关键词。
3. 片段下方显示「第 N 页」。选中文件后点击「放大预览」，或在文件区按 Space，即可跳到命中页。
4. 翻页后可点击「返回命中页」。多个关键词仍要求在同一文件中同时出现，返回第一个关键词的首个命中页，不列出全部出现位置。
5. 提取失败时在偏好设置查看原因。加密 PDF（包括空密码加密）不进入正文索引；需要密码的文件可在阅读器中输入密码阅读，但密码不交给索引、不保存。

## 资源与提取范围

| 项目 | 本版范围 |
| --- | --- |
| PDF 索引源文件 | 最大 32 MiB；原有 PDF 阅读仍为最大 64 MiB |
| 页面 | 最多前 500 页 |
| 单页输出 | 最大 256 KiB UTF-8 文字 |
| 每文件正文 | 合计最大 2 MiB，含页间分隔 |
| 提取耗时 | 页面之间检查 15 秒预算，达到后停止后续页；不是硬超时 |
| 本机派生记录 | 正文、规范化文本、位置与说明共 64 MiB，数据库／FTS／WAL 另有开销 |
| 并发 | 一个原生索引后台任务；阅读器继续单页画布 |

复用已有 `pdf-extract`，按页输出后保留页码；没有新增大型运行时。技术接口参考 [pdf-extract 官方文档](https://docs.rs/pdf-extract/0.12.1/pdf_extract/fn.output_doc_page.html)。PDF.js 继续负责阅读。

源文件与提取输出有界，但 PDF 解压、字体解析和页面内容流仍由依赖处理；这些范围不是进程内存硬限制。单次文档加载／单页解析期间不能立即打断，暂停／取消在页面之间检查。复杂字体、没有 Unicode 映射、竖排、多栏、连字可能导致文字顺序或提取质量不理想；不保证视觉阅读顺序，不提取图片里的文字。某页解析失败会令该文件失败，不将前几页误报成完整索引。

## 升级与交付

关闭拾签后运行本版安装器，沿用原安装位置并保留应用数据。标注库结构与备份／资料包格式不变。索引解析器升级为 3，旧索引在重新提取前不参与正文结果；已启用且运行的索引自动更新，暂停或取消保持，需要自行继续。标签、备注、收藏和原件保留。

正文缓存不进入标注备份或资料包。接收电脑根据本机文件自行启用索引；恢复标注备份后索引清除并关闭。
