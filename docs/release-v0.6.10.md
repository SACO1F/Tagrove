# 拾签 v0.6.10 · 图片采集 403 补救

日期：2026-10-17。

针对图片服务器返回 HTTP 403 的采集失败，新增两层处理：下载遇到 403 时，安全条件允许便携带来源站点 Referer 兼容重试一次；仍失败时，采集队列支持选择已从浏览器下载的原图。

原图补救保留任务来源、原图地址、标题和标签，由桌面文件选择窗口明确选择，不接受扩展传入任意本机路径。校验格式、大小和尺寸后保存副本；取消或选错文件保留任务。异步文件选择不阻塞工作台；结果通过队列查询，成功清除原错误并沿用回执去重。旧 403 任务可以直接补救。

不增加扩展权限，不读取浏览器 Cookie 或登录信息。来源信息仅为站点，省略路径与参数，HTTPS 到 HTTP 不发送；公网目标与逐次重定向校验继续生效。403 也可能由站点策略等导致，本轮不保证能自动下载所有受限图片。GIF／BMP 的 HTTP 类型预检与已支持的解码能力保持一致。

桌面和扩展均更新为 v0.6.10。新 EXE 路径需在偏好设置修复连接；覆盖原扩展目录后重新加载，保留队列。数据库 schema 7、资料包格式及现有库不变。
