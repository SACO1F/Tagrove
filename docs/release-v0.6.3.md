# v0.6.3 网页整理与阅读

交付日期：2026-10-16。本轮为本地交付，未上传 GitHub。

## 完成内容

- 网页资料在右侧详情与放大预览中提供“阅读／编辑／原始采集”。阅读副本可修改标题和纯文本正文；原始标题、摘录、来源 URL、采集时间及采集去重依据保持不变。
- 明确点击保存或 Ctrl＋S 提交；标题最多 300 字符，正文最多 20,000 字符。未保存草稿在本次运行中切换文件后保留，退出前提示处理；不承诺异常退出后的草稿恢复。
- 多窗口或其他整理操作导致版本变化时拒绝覆盖，保留草稿；可明确重新读取最新内容。恢复原始采集需确认，保存和恢复均支持会话内撤销。
- 修改后的标题和正文立即参加普通搜索；正文索引开启后自动重新索引。旧索引与当前修订不符时不会继续展示旧片段。阅读中高亮当前搜索词，可跳转下一处命中。
- 筛选栏支持按来源网站完整域名及网页链接／文字摘录／网页图片筛选，并可保存为集合。域名为精确匹配，不自动包含子域；填写域名后按 Enter 或移开焦点应用。
- 筛选后可 Ctrl＋A 选择结果，在批量标注中统一整理标签；标签选择支持规范名及别名，全部已有的标签不重复列出。

## 升级和交接

升级前在旧版导出标注备份，另备份重要原件。数据库升级为 schema 6，旧 v0.6.2 无法直接打开新版资料库；旧 schema 5 库升级前生成 `backups/before-web-reading-schema-v5.sqlite` 保护快照。新版本继续读取旧备份和旧资料包。

包含已保存阅读副本的资料包使用格式 6，接收方需 v0.6.3。没有阅读副本时仍按内容使用图片格式 5、链接／摘录格式 4、普通文件格式 3。原始采集和阅读副本均随标注备份、资料包保留；未保存草稿不交接。标注备份不含图片或其他普通文件原件，跨电脑仍须用资料包。

保存阅读副本会在应用管理目录写入新描述文件，再以事务更新资料记录；失败不替换旧记录。用于会话撤销的旧描述文件暂保留，不要手工清理 `captures`。网页内容以纯文本显示，不执行脚本，不下载整页，不新增 AI 请求。

Chrome 扩展版本同步为 0.6.3，协议和权限保持不变。更新扩展仍保留原目录与 Chrome 配置，替换后重新加载；移动 EXE 后修复连接。网页图片能力沿用 v0.6.2 的公开 HTTP／HTTPS、PNG／JPEG／WebP、16 MiB／4,000 万像素限制。
