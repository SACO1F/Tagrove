# 拾签 v0.3.0-beta.10／RC 稳定候选指南

日期：2026-10-10。本版为稳定候选，真实环境验收完成前继续小范围试用。

## 本轮变化

- Ctrl+A 与“全选结果”使用同一完整结果分页流程，最多 1,000 个文件；超过上限提示缩小范围，不悄悄只选已加载的一页。输入框中的 Ctrl+A 继续选择文字。
- 无原生标题栏的主窗口，在加载和前端启动错误页面保留最小化、最大化／还原、关闭及拖动区域；错误后可重试。
- 连续关闭请求共用一次保存与退出流程，避免重复触发状态检查或确认；继续遵守备注保存和后台任务退出门禁。
- 增加 Windows CI 源码／构建检查流程及本版实机验收表。CI 尚未在远端执行，其结果不能替代原生与安装验收。

## 安装与升级

本地交付目录：`releases/v0.3.0-beta.10/`。

推荐 `Shiqian-v0.3.0-beta.10-Windows-x64-setup.exe`；已有 WebView2 可用独立 EXE，仍读取 Windows 用户应用数据目录，并非把资料保存在 EXE 旁边。

升级前导出 `.sqtagbackup`，重要原文件另行备份；等待或取消任务，退出工作台与浮窗，使用同一 Windows 用户安装新版。升级后核对版本、文件、标签、备注、收藏及偏好。应用标识和数据库 schema 2 保持。

卸载器提供应用数据清除选项，需要保留标注时不要选择清除。安装器覆盖升级、缺少 WebView2、卸载重装仍需隔离测试电脑验证。实际 EXE 数据兼容与安装器升级是不同验收项。

## 同事交接

发候选安装包和从软件导出的 `.sqtagpack`，接收者通过“偏好设置 → 资料交接”校验后选择接收目录导入。资料包携带原文件和标注；`.sqtagbackup` 只备份标注、备注、路径与相关设置，不携带原文件或 AI 密钥。

完整说明保存在源码快照 `docs/user-manual-v0.3-beta9.zh-CN.md`，基础操作仍适用；版本差异以本指南为准。

## 使用与退出

资料包任务可后台运行，从任务面板查看、重试或取消。准备期间可浏览和保存备注，最后提交可能短暂等待。普通文件导入取消后已完成记录保留。

浮窗显示时关闭工作台会隐藏主窗口，可从浮窗重新打开；完全退出先关闭浮窗再关闭工作台。加载错误时窗口按钮仍可用，后台任务仍受退出检查保护。

## 验收与反馈

验收范围见 Beta.10 验收记录（历史资料，见 v0.6.12 源码快照）。实机清单在源码快照 `docs/beta10-rc-checklist.md`，干净系统、物理鼠标、多屏混合 DPI、不同电脑交接及全天运行需填写真实结果。

诊断报告仅包含版本、计数与状态，不含文件名、路径、正文、备注、标签文字或 AI 服务配置，不自动上传。

## 开发与交付

执行 `npm ci`、`npm run build`、`cargo test --locked --manifest-path src-tauri/Cargo.toml --lib` 和版本门禁，再完成生产桌面回归与安装包构建。`scripts/package-release.py` 校验六处源码版本、两个程序版本、源码 ZIP 和发布资产 SHA-256。

本地候选包不等于 GitHub 已发布版本。正式稳定发布需满足实机清单门槛。
