# 拾签 v0.3.0-rc.4：列数过渡与连续缩放稳定

日期：2026-10-11。Windows 11 x64 正式可用版交付。安装包保留 0.3.0-rc.4 版本号；本版按项目负责人决定作为推荐日常使用版本发布。

## 本轮修改

- 列数加减和滑块变更前记录可见卡片的位置，变更后播放 300ms 位移/缩放过渡，原有图标和标签尺寸抵消机制继续有效。
- 连续调整窗口时，卡片即时跟随可用宽度，不对每个尺寸变化重启 300ms 动画。停止调整后，下一次列数操作或详情展开仍正常播放动画。
- 宽度变化更新文件的布局高度，保留已分配的列；仅实际列数变化由虚拟布局重新分配，避免逐帧 measure() 清空列缓存造成左右跳动。
- 高度估算同步覆盖未显示的文件，挂载卡片再以实际布局高度校正，避免滚动后的旧高度造成重叠。
- 减少动态效果模式继续跳过过渡。图片、Markdown 图标、标签和详情位置的上一轮修复继续保留。

## 升级与交付

安装包：`Shiqian-v0.3.0-rc.4-Windows-x64-setup.exe`。升级前保留原文件并导出标注备份，关闭旧版工作台与浮窗，卸载时保留应用数据。
