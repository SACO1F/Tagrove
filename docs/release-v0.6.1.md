# 拾签 v0.6.1 · 采集可靠性与连接排障

交付日期：2026-10-16。桌面与 Chrome 扩展均为 0.6.1；本轮本地交付。

## 本轮改动

- 右键采集改为独立草稿 ID，连续打开不会覆盖；草稿上限 20 份／24 小时，提交进入队列后清理。
- 支持普通文本框、多行文本框选区；明确排除密码框。未检测到选区或页面限制读取时给出下一步提示。
- 队列增加单项重试、尝试次数、最近尝试时间、具体错误码及处理建议；页面自动反映队列变化。
- 区分需要重新处理的内容／协议问题与可恢复的连接／存储问题，避免无意义的自动重试。缺少有效桌面回执不计为已保存。
- worker 启动时检查并补建自动重试定时任务，旧队列保留原请求 ID。
- 桌面偏好设置增加注册状态、“修复连接”和“移除本机连接”。Windows 注册使用 Unicode API；连接文件原子替换。移除保护其他位置及其他资料库的连接。

## 升级与文件

退出旧版并导出备份，再运行 `Shiqian-v0.6.1-Windows-x64.exe` 或安装 `Shiqian-v0.6.1-Windows-x64-setup.exe`。扩展包为 `Shiqian-v0.6.1-Chrome-extension.zip`。

扩展更新请在原安装目录替换文件，在 Chrome 扩展管理页保持开发者模式并点击“重新加载”，核对 0.6.1；不要卸载或清理扩展数据。详见 扩展说明（历史资料，见 v0.6.12 源码快照） 及扩展 ZIP 内 README。

数据库仍为 schema 4、含网页资料包仍为格式 4，与 v0.6.0 兼容；v0.5.x 不能直接打开该数据库。新版支持 v0.6.0 未完成队列继续发送。本版没有自动执行浏览器连接迁移，独立 EXE 移动后请手动修复连接。
