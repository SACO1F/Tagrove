# 拾签 v0.3.0-rc.2：资料包分类与详情过渡修复

日期：2026-10-11。平台：Windows 11 x64。RC.2 为候选修复交付，未正式发布稳定版，也未上传本轮 GitHub Release。

## 本轮五项修改

1. 导出资料包的交接范围采用工作台现有 Glide Select：弹出/收回、滑动高亮、键盘方向键/Enter/Escape，保持绿色主题与浅深色风格。参考 React Bits Glide Select 的交互；没有引入额外图标依赖。
2. 新 v2 包记录文件的直接父文件夹名，接收目录按 Pic、Desktop 等分类，不再给每个文件建立一个数字目录。包内归档编号仍用于隔离同名条目，用户接收目录不使用这些编号。相同目录名归入同一分类，文件重名则添加编号后缀，保留内容。
3. 详情开启后首次选择文件，以该文件为中心定位，避免布局缩窄后选中卡片离开视野。手动反复开关详情保持原滚动位置。
4. 移除详情宽度逐帧触发瀑布流重排的做法，先提交最终几何，再对卡片位移与缩放做 300ms 缓进缓出动画。测量使用布局高度，不把视觉缩放混入虚拟列表的高度缓存。减少动态效果模式跳过卡片动画。
5. 「已选」栏保持文字与图标节点、固定指示器占位，短请求延迟显示加载图标；避免从 4px 小点换成 13px 图标时挤动文字。单纯点击选择并不主动重新查询全部文件，详情宽度变化或后台加载也会造成原先的视觉抖动。

## 资料包兼容与升级

**交接双方需升级至 RC.2 或后续支持 v2 的版本。** 新版读取旧 v1 包；旧版不能读取新 v2 包。新包只保留直接父目录名，不复制盘符和完整源目录树。

旧 v1 包按文件夹来源标签归类；没有目录信息时放入「未分类」。已导入的数字目录不自动搬动。需要重新交接时，发送端导出新的包；接收端核对后再处理旧记录和旧文件，程序不会自动删除这些资料。重复包收据仍保护同库不重复导入。

安装包：`Shiqian-v0.3.0-rc.2-Windows-x64-setup.exe`。升级前导出标注备份，保留原文件，退出旧版与浮窗，卸载时保留应用数据。
