# v0.6.8 AI 标签边界与阅读间距

日期：2026-10-16。本轮本地交付。

- 文件夹标签不进入发给 AI 的候选池，也不计入候选数量上限。模型返回目录标签 ID 或目录名时会过滤，落库前再次检查，防止变成待确认建议。
- 浏览器采集链接、摘录和图片，只要用户已经选择标签，就只保存资料并添加所选标签，不自动识别。未选标签时仍按桌面 AI 开关排队；显式手动识别保持可用。
- 重复采集时补选标签，会取消该文件仍在排队／运行的识别结果接收，防止稍后又出现自动建议。已发出的服务请求可能仍计费；已完成的历史建议不自动清除。
- 阅读副本的阅读／编辑／原始采集工具栏，下方分隔线与网页链接类型、来源内容之间增加 20px 留白。
- 扩展保存页面同步说明“已选标签跳过 AI”。数据库 schema 7、资料包格式、默认在线／原排版及副本保存方式保持。

升级前备份并退出旧程序；运行新版 EXE 或安装包。配套扩展同步为 0.6.8，在原目录替换后重新加载；移动 EXE 后修复连接。此规则主要由桌面端执行，旧桌面不会获得新策略。
