# 拾签 v0.5.1：Office 正文检索与来源定位

2026-10-12。本地开发交付；公开 GitHub 下载仍为 RC.4，本轮未上传。

## 新增功能

- 「文件内容」搜索增加 DOCX、XLSX、CSV、TSV，与现有 TXT／Markdown 共用本地索引。搜索实际提取的正文，不以卡片摘要代替。
- DOCX 搜索主文档段落及表格，结果显示段落或表格行列来源；不搜索页眉、页脚、批注、文本框或图片文字。
- XLSX 搜索所有可提取工作表，结果标明工作表和单元格，例如「明细 · B5000」。CSV／TSV 显示数据表单元格位置，支持引号、换行、UTF-8、带 BOM 的 UTF-16、GB18030。
- 选中命中的 Office 文件并「放大预览」，阅读器定位并突出显示该段落、表格或单元格。切换工作表或滚动后，可点击「返回命中位置」。Word 定位使用内容段落，不是印刷页码。
- 搜索仍可与标签、目录、类型、收藏及其他已有筛选共同生效。多个空格分隔的词在同一文件内同时匹配，显示第一个关键词的首个命中位置。
- 从 v0.5.0 升级后，启用中的旧正文索引自动按新解析器更新；暂停状态保持，继续后更新。文件和原有标签、备注、收藏无需重新导入。

## 本轮搜索与列表体验修订

- 空搜索及清空关键词后，不生成或保留正文片段。每份命中携带当前查询，旧查询结果在新查询完成前隐藏；片段按当前关键词更新，并突出显示关键词。
- 列表标签按实际可见范围判断，不再用固定 75 px 上限缩短名称。全部标签完整可见时，鼠标悬浮或键盘聚焦不重复弹出标签浮层；超出列宽时才显示全部标签。
- 文件夹标签保存完整目录名；列表和侧栏可换行，不用省略号替代。普通手工标签仍保留 40 字符限制，自动文件夹标签支持最多 255 个字符。旧自动省略标签仅在文件路径能确定来源且没有名称冲突时恢复，保留标签身份；用户改名不自动覆盖。
- 文件名称、标签、修改时间、大小的列边界可拖动调整。表头悬浮时出现手柄，平时隐藏；双击恢复默认，键盘左右方向键也可调整。列宽在本机 WebView 偏好中保存；窄视口保留修改时间和大小，空间不足时可横向滚动，大小列与表头左侧对齐。
- DOCX、XLSX、HTML、Markdown 采用不同几何符号与颜色的线框图标。列表图标背景透明，无阴影；图片和 PDF 预览保留。
- Markdown 使用居中的灰色 M，去掉向下箭头；深色主题使用浅灰保证可读性。HTML 在瀑布流和列表中统一使用代码括号图标。
- 清空搜索按钮和删除输入至空白会立即清空查询；无关键词时不显示上次命中的正文片段，再次搜索使用当前关键词。
- 标签表头和每行采用相同的列宽、间距和边界，宽／窄窗口下标签左侧保持对齐。
- 文件内容搜索时，卡片文件名下方是命中的正文片段；下方小字显示段落或单元格来源、编码和「部分内容」提示，不是 AI 生成的摘要。

## 使用方法

1. 偏好设置 → 正文索引 → 启用索引。默认关闭，不需要 AI、联网或安装 Microsoft Office。
2. 点击工作台搜索图标，选择「文件内容」，输入文档中的词。
3. 结果显示片段和来源；选中文件后放大预览，或在文件区聚焦时按 Space，查看命中内容。
4. 损坏、加密或超出源文件预算的文档会显示失败原因；修复后可重建索引。暂停、取消、重建、清除和重启恢复沿用现有流程。

## 提取和资源边界

DOCX／XLSX 源文件上限 **32 MiB**，CSV／TSV **8 MiB**。Office 每文件提取最多 **2 MiB UTF-8 正文、20,000 个非空来源位置**；ZIP 每项 XML 上限 8 MiB、累计 XML 24 MiB、最多 5,000 个条目。XLSX 最多 100 张表，每表保留现有 10,000 行、100 列、100,000 单元格、单元格 4,096 字符的边界。DOCX 主文档最多 5,000 个可预览内容块，每表最多 1,000 行、100 列。CSV／TSV 保留 10,000 行、100 列、100,000 单元格边界。达到范围时明确标记「部分内容」，未提取的尾部不能搜索。

XLSX 检索单元格**原始值和文件内已有的公式缓存值**，不计算公式、不检索公式表达式。无保存结果的公式不会生成搜索内容；日期、百分比、货币等搜索采用原始数字，不保证按预览中的格式化文本匹配。图表和扫描文字不提取，旧 DOC／XLS、PPT／PPTX、加密 Office 不支持。

正文、规范化正文、来源记录及范围说明合计预算 **64 MiB**；FTS、数据库、WAL 日志存在额外开销，该预算不是总磁盘或进程内存上限。DOCX 索引不加载内嵌图片，XLSX 的共享字符串和工作簿资源在每次提取中只读取一次。未新增完整 Office 引擎。

索引是独立派生缓存，不写原文件、不调用 AI、不随资料包或标注备份传送。关闭功能保留缓存，清除才删除正文记录。恢复标注备份会清除并关闭索引；接收电脑自行主动启用。PDF 正文检索安排在 v0.5.2；现有 PDF 预览继续可用。

## 安装与重点验证

推荐 `releases/v0.5.1/Shiqian-v0.5.1-Windows-x64-setup.exe`。升级前导出标注备份、退出工作台和浮窗，在原 Windows 用户下安装并保留应用数据。

重点测试自己的多工作表中文表格、长 Word、常用 CSV 编码、暂停后重启，以及旧版本升级后标签／备注／收藏是否保留。真实第二台电脑、混合 DPI、网络盘和长时间使用继续按实机验收清单补齐。
