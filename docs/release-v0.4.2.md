# 拾签 v0.4.2：Office 只读内容预览

2026-10-11。本轮本地交付；v0.4.1 已用于侧栏、PDF 上限及 HTML 更新，因此 Office 首版顺延为 v0.4.2。公开下载仍为 RC.4，本轮未上传 GitHub。

## 新增能力

选中文件，在详情点击「放大预览」，或文件区聚焦时按 Space：

- DOCX：阅读中文正文、标题、粗体／斜体及基本表格，虚拟滚动长文档。
- XLSX：工作表切换、固定列标题和行号、双向滚动；虚拟呈现可见行。显示保存的值及公式缓存结果，无结果时明确提示，悬停查看完整内容。
- CSV／TSV：表格阅读，识别引号、换行与 UTF-8／UTF-16／GB18030 文本。
- 沿用主题色、浅色／深色及 Glide Select 下拉样式。已有导入记录无需重新加入，无需安装 Office。

## 范围与预算

首版为内容阅读，卡片仍显示类型图标。DOCX 不还原分页、图片、文本框、编号和复杂排版；XLSX 显示原始值，不还原日期／数字格式、图表和合并单元格，不重新计算公式。旧 DOC／XLS、PPT／PPTX 和加密 Office 暂不支持。

DOCX／XLSX 文件上限 32 MiB；CSV／TSV 为 8 MiB。工作表最多 10,000 个记录行、100 列、100,000 单元格，超出显示截取提示。ZIP 最多 5,000 条目；单项 XML 8 MiB，累计读取 XML 24 MiB，每项最多 200,000 节点及 64 层结构深度。DOCX 最多 5,000 个正文块，单表 1,000 行／100 列。达到结构预算时提示打开原文件。

后端仅通过已导入文件 ID 读取，校验身份及修订；不解压到磁盘、不解析外部实体、不读取外部资源，不执行宏或公式。前端将解析值作为 React 文本呈现。关闭或切换工作表后忽略旧请求的 UI 结果；后端读取受预算约束，不承诺即时中断正在进行的解析。

复用现有 ZIP、XML 与虚拟滚动依赖，无新增 Office 引擎。安装器约 5.72 MiB，较 v0.4.1 增加约 27.0 KiB。测试边界见验证记录。无数据库结构迁移；升级前导出标注备份，退出旧软件，安装时保留应用数据。

交付目录 releases/v0.4.2/，包含安装器、独立 EXE、源码 ZIP、文档及 SHA256。旧版本安装包保留。
