# 拾签 v0.3.0-beta.2 使用与交付

日期：2026-10-10。主项目：`D:\AI\Shiqian`。本版聚焦后台任务、资料包导入响应、备份状态、恢复提示与本地诊断。

## 安装与升级

本地交付目录：`releases/v0.3.0-beta.2/`。

- 推荐安装包：`Shiqian-v0.3.0-beta.2-Windows-x64-setup.exe`。
- 独立程序：`Shiqian-v0.3.0-beta.2-Windows-x64.exe`，仍依赖系统 WebView2，使用 Windows 用户应用数据目录。
- 升级前导出 `.sqtagbackup` 标注备份，重要原文件另行备份。退出工作台与浮窗，安装新版后核对文件、标签、备注、收藏和设置。
- 数据库格式保持 schema 2，与 Beta.1 共用既有资料库；schema 1 的保护副本与迁移机制继续保留。
- 首次安装、缺少 WebView2、覆盖安装和卸载的数据保留行为需在独立测试电脑验证。程序构建完成不代表这些环境已通过验收。

## 后台任务

工作台底栏新增「任务」入口，可查看文件加入、AI 分析和最近的资料包任务。

资料包校验、导入或导出开始后，点击「后台运行」即可回到工作台。任务继续执行，可以浏览、搜索和编辑既有文件的备注。再次点击底栏任务入口查看进度或取消。

进度按当前阶段显示：校验、打包或复制分别计算字节和文件数量；进入「保存标注」后显示记录数量。阶段切换会重新计数，不把同一文件的重复读取累加成完成百分比。

- 资料包最近记录保留本次运行的 12 项，区分完成、失败与取消；重启后会话记录清空。
- 资料包失败后查看原因，再从资料交接入口重新校验和执行；成功导入记录可以打开接收文件夹。
- 文件加入失败可只重试已记录的路径，最多保留 100 个失败路径；目录读取失败重试时会重新扫描该目录，已存在的记录复用。
- AI「重试失败项」只重排失败任务，已完成、未支持和主动取消的任务不重新识别。AI 配置必须已启用。
- 资料包任务期间新的文件加入和备份恢复会被阻止；恢复开始后不能取消。退出前需等待任务结束，或取消资料包任务并等待清理完成。

复制与校验在资料库锁之外完成；最后保存标注仍需要短事务。最终提交大量记录时，其他资料库操作可能短暂等待。

## 备份和异常恢复

「偏好设置 → 备份与恢复」显示最近一次手工标注备份或恢复前保护备份的日期。旧版本没有记录的备份显示「尚未记录」，不会推测不存在的历史。

`.sqtagbackup` 包含标注、文件位置和界面设置，不包含原文件与 AI 服务配置。跨设备交接文件和标注应使用 `.sqtagpack`。

如果上次资料包导入或备份恢复中断，底栏显示「恢复提示」。提示会跨启动保留，直到用户查看并点击「已了解」。打开数据目录可查看 `backups/` 下的恢复说明和保护备份。

中断导入留下的文件继续保留，不会自动删除。根据提示检查接收文件夹，移走或删除残留后重新导入。点击「已了解」只关闭提示，不清理文件。

## 诊断与反馈

打开「偏好设置 → 预览诊断报告」，查看报告后导出 Markdown 文件。

诊断采用固定字段：应用版本、系统种类与架构、数据库格式、文件及标签计数、不可用文件计数、AI 任务计数及资料包任务状态。文件名、路径、正文、备注、标签名称、AI 服务地址、模型和密钥不写入报告，也不自动上传。

反馈问题时，附上诊断报告、发生步骤和是否稳定复现即可。诊断报告不包含界面截图；截图由用户自行选择。

## 发给同事

发送本版安装包和通过软件导出的 `.sqtagpack`。同事在「偏好设置 → 资料交接 → 导入资料包」选择包、校验、选择接收目录并确认导入。原文件、标签来源、备注与收藏一起追加，导入不触发 AI。

资料包限制仍为 10,000 个文件 / 8 GB 原文件；同包在同一库只导入一次，同名文件通过编号目录分开保存。

实测范围和待验收项目见 Beta.2 验收记录（历史资料，见 v0.6.12 源码快照）。开发格式与 API 约定见 资料包格式 v1（历史资料，见 v0.6.12 源码快照）。

干净电脑、跨设备、显示器和全天试用可使用源码内 `docs/beta2-real-device-checklist.md` 记录结果。
