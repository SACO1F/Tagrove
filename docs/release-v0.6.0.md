# 拾签 v0.6.0 · 浏览器采集首版

交付日期：2026-10-16。Windows x64 本地交付，未发布 GitHub。应用与扩展版本均为 0.6.0。

## 新增内容

- Chrome MV3 扩展保存网页链接或选中文字，允许编辑标题、来源与摘录。
- 网页资料进入“全部资料”，复用标签、备注、收藏、类型筛选和启用后的正文索引。
- 详情阅读纯文本摘录、查看采集时间并打开来源；支持内容滚动和 Ctrl＋滚轮缩放。
- 在偏好设置明确连接本机扩展。桌面未运行时留在 Chrome 本地队列，启动后重试；回执与内容去重避免重复入库。
- 标注备份／资料包保留网页来源和摘录；接收端安全重建描述文件。

## 取用

本目录中的 `Shiqian-v0.6.0-Windows-x64.exe` 可直接运行；`Shiqian-v0.6.0-Windows-x64-setup.exe` 用于安装；`Shiqian-v0.6.0-Chrome-extension.zip` 解压后在 Chrome 加载，具体见 扩展安装说明（历史资料，见 v0.6.12 源码快照） 和扩展 ZIP 内 README。

日常操作见 中文使用说明（历史资料，见 v0.6.12 源码快照） ／ English manual（历史资料，见 v0.6.12 源码快照）。测试报告（历史资料，见 v0.6.12 源码快照） ／ 验证与待验收（历史资料，见 v0.6.12 源码快照） ／ 下一阶段计划（历史资料，见 v0.6.12 源码快照）。

## 升级注意

先退出旧程序，导出标注备份并备份重要原文件，再运行或安装新版；安装向导卸载旧版时保留用户信息。不要同时运行两版写同一资料库。

本版数据库升级至 schema 4，旧版不能直接打开升级后的库。升级时有保护备份；若要退回，请使用旧程序兼容的升级前备份，不要把新备份交给旧程序恢复。含网页资料的格式 4 资料包需接收方 v0.6.0；只有普通文件的包仍是格式 3。
