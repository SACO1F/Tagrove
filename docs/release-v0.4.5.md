# 拾签 v0.4.5：路径修复

2026-10-11。本轮本地开发交付，公开下载仍为 RC.4，未上传 GitHub。

## 新增内容

偏好设置新增「文件位置 → 修复文件路径」。输入旧目录与新目录，先预览，再确认更新引用。支持目录移动、改名、换盘后的重新定位，并保留文件记录身份、普通标签、备注与收藏；文件夹标签按既有偏好更新。原文件不搬动。

- 结果区分已验证、待确认、多个候选、未找到、路径或内容冲突。唯一已验证候选默认选择，其余须核对。候选只来自本次扫描，提交不接受任意新路径。
- 按组件判断目录范围，以相对路径、文件身份和名称特征定位。原文件可用时在预算内按需比较 SHA256；已知内容不同的候选不能确认通过。
- 原文件已经丢失且没有可靠内容基线时，候选必须手工核对；同名、同大小不视为已验证。
- 提交前重新核对文件、记录版本和相关设置；一次数据库事务更新，任何失败整批回滚。修复形成一条会话撤销记录。
- 可同步当前目录筛选与保存集合的目录条件。条件整体映射，未修复记录保留旧路径，界面提供提示与开关。
- 扫描可取消，结果分页 25 条，筛选分类沿用工作台下拉样式。

## 范围与预算

一次最多 1,000 条旧目录记录，新目录最多 20,000 条目／32 层；符号链接及连接目录不递归，应用数据目录排除。最多显示 8 个重名候选。SHA256 单文件最多 64 MiB、每次读取最多 256 MiB，超预算时需确认。预览有效期 15 分钟，文件变化需重新扫描。

不新增运行时依赖，不迁移数据库，不自动监听目录。撤销沿用当前会话历史，重启后不能撤销。跨盘、网络盘、多屏与长时间使用继续按实机清单补证据。
