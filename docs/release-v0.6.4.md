# v0.6.4 本机引擎与预览增强

日期：2026-10-16。Windows x64，本地交付版本。

## 本轮功能

- Office 增加“原排版”模式，通过本机 Microsoft Office、WPS Office 或 LibreOffice 生成只读分页预览，复用 PDF 连续阅读、缩放与文字选择；现有内容预览保留。
- DOC／XLS／PPT 旧格式接入同一路径；内容模式先生成临时 DOCX／XLSX／PPTX，再交给现有段落、工作表、幻灯片内容阅读器。源文件不覆盖，不向资料库添加转换副本。
- 按文档类型检测独立接口；默认 Microsoft Office → WPS → LibreOffice，可手动选择并记住偏好。两个品牌同时安装不会由拾签修改默认文件关联。若接口被别的软件接管，进程品牌检查会拒绝错误引擎。
- 本轮保守地拒绝复用正在运行的同类 Office 应用，请先关闭所选应用或选择其他引擎。不会为了预览关闭用户的办公软件。首次转换耗时数秒，后续使用按文件版本与引擎区分的本地缓存。
- 没有可用引擎时，“按需安装增强预览组件”打开 LibreOffice 官方下载页。用户自行安装后点“检测引擎”。本安装器不附带整个办公套件。
- PDF 可选择已有文本；扫描件需要 OCR 才能选择文字，OCR 不在本轮加入。
- 网页资料新增“在线网页”，在独立 WebView2 区域加载来源网页，可前进、后退、刷新、查看当前地址及外部打开。网页使用独立配置目录，不共享 Chrome 登录状态；未点击前不加载在线页面。
- 在线网页无法访问资料库 API；只允许 HTTP／HTTPS 导航，新窗口和网页下载关闭。打开本地对话框时隐藏网页区域，返回阅读副本或切换文件时销毁网页视图。
- 网页图片上限提高到 50 MiB、1 亿像素；增加 GIF／BMP。保存原始字节，GIF 内置预览显示首帧。解码预算与缩略图像素上限同步调整，仍拒绝私网、SVG、登录信息透传及 blob／data 地址。

## 升级与交接

先使用旧版导出标注备份并备份重要原件。资料库升级为 schema 7；schema 6 升级前生成 `backups/before-preview-image-schema-v6.sqlite`。旧版不能直接打开新版库；不要降级覆盖新库。

网页图片资料包本轮使用格式 7，接收方须 v0.6.4；阅读副本包仍使用格式 6，链接／摘录格式 4，普通本地文件格式 3。新版本继续导入旧资料包与旧备份。跨电脑交接应使用资料包，标注备份不包含原件。

## 验证边界

本机具有 Microsoft Office，未安装 WPS 和 LibreOffice。Microsoft 六种新旧格式的真实转换已通过；WPS 与 LibreOffice 的适配入口已实现，实际转换、两个品牌共存仍待对应设备验收。SmartArt 经引擎输出静态外观，不包含动画与编辑能力；本机 SmartArt 布局对象不可用，复杂 SmartArt 的实际还原尚未验收。不能承诺任何复杂文件完全一致。
