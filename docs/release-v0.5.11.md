# 拾签 v0.5.11：大资料库与恢复维护

本地 Windows x64 交付。保留既有搜索、阅读、标签和资料包工作流。本轮没有上传 GitHub。

- 诊断报告增加标注库、正文索引、语义索引与预览缓存占用，正文任务、语义任务、阅读状态数量和待完成恢复状态。仅在用户打开／导出诊断时读取，常规备份状态轮询不扫描缓存。
- 恢复旧备份后立即补齐阅读状态表，无需重启即可继续阅读与保存位置。
- 恢复流程中断后的首次打开，暂停目录监听、取消待发送 AI 任务、关闭 AI／语义服务配置并清除派生索引；成功收尾才删除恢复标记，避免旧结果混入或自动重发请求。用户可重新设置服务并手动建立索引。
- 导出备份不覆盖同名文件；请选择新文件名。恢复前仍先保留保护备份，标注备份不包含原文件。
- 正文片段已覆盖所有查询词时提前停止候选扫描，并复用首词定位，减少重复正文读取。保留 v0.5.10 命中原因和排序规则。
- 建立 1,000／10,000 混合记录的桌面测试与资源报告，包含真实合成图片、PDF、DOCX、XLSX、Markdown、HTML 和失效路径。

Fuse.js 仅加入后续计划，未安装依赖、未接入检索，也未替换语义补充。

使用前退出旧版并导出标注备份。实机升级、断电、磁盘写满、多屏 DPI 和长时间使用仍需单独验收；本轮规模测试不代表全部记录都拥有可读取原文件。
