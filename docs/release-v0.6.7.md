# v0.6.7 默认预览与加载细化

日期：2026-10-16。本轮本地交付，尚未发布 GitHub。

- 引擎检测在后台进行，不再显示检测画框或扫光；重新检测时保留已有预览。未发现引擎、检测失败等结果仍会显示。
- 真正生成原排版 PDF 时，画框、扫光和“正在生成原排版预览”文字作为一组，在内容区域水平、垂直居中；减少动态效果下停止扫光。
- 网页资料的详情与放大预览默认在线网页；Office 默认原排版。切换到阅读副本、内容预览仍可本地阅读。打开网页资料会联网访问来源，不共享 Chrome 登录状态。
- 保存阅读副本后保留当前阅读界面，不因记录版本更新突然跳回在线网页。切换文件重新打开时仍采用默认在线模式。
- 图片、PDF、本地 HTML 与 Markdown 保留对应阅读器；首次缩放仍为适合页面，已有手动缩放继续恢复。

## 阅读副本的三个按钮

| 按钮 | 用途 | 是否修改内容 |
|---|---|---|
| 阅读 | 查看当前本地文字副本；没有副本时使用原始标题、摘录 | 否 |
| 编辑 | 修改副本标题、正文，并明确保存 | 仅修改拾签内的本地副本，不修改网站 |
| 原始采集 | 只读对照最初采集的标题、摘录、来源 | 否，也不会撤销编辑 |

“恢复原始采集”是另一个需确认的操作，会移除保存的副本。原始网页链接可能只有标题和 URL，扩展正文摘要属于阅读副本，不保证原始摘录包含整页正文。在线网页为实时网站，阅读副本为本地纯文本，均不代表完整离线归档。
